# 다이버전스+양봉 자리만 사기 vs 나머지 신호를 직후에 사기 (측정)

> 2026-11-24 등록. 계기: 진입 타이밍 측정(docs/lowpoint_entry_timing.md) 뒤 Claude 보고 "이 자리는 신호의 약 20%에서만 나와. 나머지 80%
> 신호를 건너뛰는 게 낫다는 뜻은 아니야. 그 비교는 안 했어." → 사용자 "비교해봐".
> 분류: **H1 판정 측정** (두 독립군 비교, 결과 지표 3개).

## §1. 사전등록 (실행 전 고정)
- 표본: 진입 타이밍 측정과 같은 신호 표본(11-10 trades 중 상장 1년+ · 신호 뒤 120+250봉 · 무효봉 종목 제외 = 1,433신호, 같은 캐시).
- **B군** = 그 측정의 B 매매(다이버전스+양봉 다음 날 시가, 짝 288건) — 결과 JSON의 `cand` 그대로.
- **N군** = 120거래일 안에 다이버전스+양봉이 **안 나온** 신호의 직후 매매(`system` 그대로). 판정은 `divergence.entry_signal`(운영 칩·측정 B와
  같은 날을 고르는 함수). 트리거는 났는데 B 매매에서 빠진 신호(같은 트리거 중복·갭 +5%)는 두 군 모두에서 뺀다(수 기록).
- 질문: "B가 안 나오는 신호를 건너뛰어도 되나" = 건너뛰는 매매(N)가 B보다 나쁜가.
- 지표(B − N): **O1(주)** 20거래일 안 +5% 비율(두 비율 z) · O2 건당 수익 Welch z · O3 묶임률(N − B, 양수 = B가 덜 묶임).
  Bonferroni 3 → z ≥ 2.39. 반분(신호일 중앙값) 양쪽 같은 부호. 각 n ≥ 100.
- 판정: **B 우위** = O1 z ≥ 2.39 · 반분 양쪽 B > N → "건당 질은 B가 낫다". **N 우위** = O1 z ≤ −2.39 · 반분 양쪽 B < N.
  그 외 **차이 없음** → 건너뛰면 기회만 줄어든다(N도 같은 질). n < 100 → 판단 불가.
- 기록만: 100자본일당 수익(ret ÷ cap_days × 100, 자금이 묶인 시간 대비) 평균, 연간 매매 수(빈도).
- 실행 시각: `harness.check_run_window(("kr",))`.

- 해석: B 자리를 기다려 산 매매는 "다이버전스가 안 나온 신호를 바로 산 매매"와 같은 질이다. **N을 건너뛰면 매매 기회만 약 4분의 1로 줄어든다.**

  나머지 신호를 버릴 근거가 아니다.
