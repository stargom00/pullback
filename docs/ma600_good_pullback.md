# 600일선 기준봉 뒤 "좋은 되돌림" 진입 — 사전등록

> **⚠️ 데이터 한계(먼저 읽을 것)**: 사용자 정의 "좋은 되돌림"의 ④ **LTF 가격 반응은 잴 수 없다** — naver 분봉은 최근 6거래일만 남아
> 과거 분봉이 없다(CLAUDE.md "저점 관찰 도달 판정", 2026-10-07 실측). 이 측정은 ④를 **일봉 반전봉**(눌림·②·③ 뒤 양봉이면서 종가 > 전일
> 고가)으로 대체했다. 결과는 "일봉 반전봉" 정의에 대한 것이지 원래 ④에 대한 것이 아니다.

> **상태: 사전등록(2026-10-09). 미실행 — 해석 기본값 사용자 확인 대기.** 짝 측정: docs/ma99_good_pullback.md(선 길이만 99). 실행 순서 600 → 99.
> 순서: 사전등록 커밋 → 해석 기본값 확인 → 실행 → 결과. **결과를 본 뒤 조건 변경·재실행 금지.**
> 실행 시각: `harness.check_run_window(["KR"])`. 등록부: docs/measurement_registry.md.

- 스크립트: `scripts/measurements/2026-10-09_ma600_good_pullback.py`(결과 JSON 커밋 안 함). 99일선: `2026-10-09_ma99_good_pullback.py`(이 모듈
  import, 선 길이만 99). 테스트: `test_good_pullback.py`.

## §0. 왜 재는가 — 설계 오류를 바로잡는 측정 (명시)

| # | 측정 | 진입 | 결과 |
|---|---|---|---|
| 1 | 저점 출발(+5% 고가) | 다음 날 종가 | 기각 z −8.08 |
| 2 | 기준양봉 출발 | 다음 날 종가 | 기각 z −7.33 |
| 3 | 장대양봉 지지 확인 | 눌림·지지선·확인봉 → 다음 날 시가 | 기각 z −6.08 |
| 4 | 600일선 돌파 장대양봉(a732920) | **다음 날 시가** | 기각 z 0.75 |
| 5 | 99일선 돌파 장대양봉(a732920) | **다음 날 시가** | 기각 z −11.07 |

- **설계 오류(사용자 지적)**: 4·5는 진입을 "다음 날 시가"로 잘못 설계했다. 사용자 의도는 **장대양봉 이후의 좋은 되돌림에서 들어가는 것**이다.
- 사용자 정의 "좋은 되돌림": ① 상승 기준봉 출현 ② 매물대 ③ 주요 이평선 10~50 ④ LTF 가격 반응(→ 일봉 반전봉으로 대체, 맨 위 한계).
- **다중 검정**: 같은 데이터로 **일곱 번째 검정 → Bonferroni 7, z ≥ 2.69**(600·99 둘 다).

## §1-구현

| # | 항목 | 정의 |
|---|---|---|
| G1 | 데이터·유니버스·정제·저유동성·A/C | 600일선 돌파 스크립트(a732920)의 `load_data`(3,000일 캐시)·`candidate_bars`·`classify(p, 600)`·`ma_at`을 import. C = 전일 종가 < 선 그리고 당일 종가 ≤ 선(a732920 C와 같음). |
| G2 | 매물대 | 기준봉 **전일까지** 정제 데이터로 `supply_profile(종가, 거래량, last = 전일 종가)["zone"]` → {하단, 상단}. 없으면 미진입(`no_zone`). |
| G3 | 확인봉 탐색 `find_entry` | 기준봉 다음 유효 거래일부터 1, 2, …, 20. 매일 ① **이탈 먼저**: 종가 < 매물대 하단 또는 종가 < MA50이면 미진입(`break_zone`/`break_ma50`/`break_both`) ② 눌림·②·③이 **앞선 봉들에서** 모두 충족됐고 양봉·종가 > 전일 고가면 확인봉 ③ 그 봉으로 표시 갱신: 종가 < 기준봉 종가 → 눌림, 저가 ≤ 매물대 상단 → ②, min(MA10, MA50) ≤ 저가 ≤ max → ③. MA10·MA50은 그날까지 정제 종가 단순평균. |
| G4 | 미진입 사유 | 20일 안에 확인봉 없음 → 눌림 없음(`no_pullback`) / ②만 실패(`fail_zone_only`) / ③만 실패(`fail_ma_only`) / 둘 다 실패(`fail_both`) / 셋 다 됐는데 확인봉 없음(`no_confirm_bar`). 데이터가 20일 전에 끝나면 `window_incomplete`. |
| G5 | 진입·손절·청산 | 확인봉 다음 유효봉 시가(지지 확인 스크립트의 `race_open` — 확인봉까지 데이터로 저유동성 판정), 손절 = 기준봉 다음 날~확인봉 최저 저가, `harness.race`(진입봉 포함, 저가 ≤ 손절 −1R · 고가 ≥ 2R · 60봉, 같은 날 손절 우선). 진입가 ≤ 손절가면 제외. |
| G6 | 겹침 | 종목마다 기준봉 시간순. 이미 잡은 포지션 기간(진입봉~청산봉) 안에 기준봉이 있거나 진입봉이 들어가면 건너뜀(A·C 공통). |
| G7 | 판정 | `harness.ev_gap_zscore(C, A)` 단측 z ≥ **2.69**. 반분 = A 진입일 중앙값. A·C 각 nv ≥ 100이 아니면 판정 불가. |
| G8 | 기록 전용 | 진입가 대비 D+63(진입봉을 1번째로 63번째 유효봉 종가, 그 63봉 최고 고가·최저 저가), 미진입 사유별 건수(A·C), 기준봉→확인봉 거래일 수 분포, 1R% 분포. |
| G9 | 실행 중 수기 대조 | 진입 이벤트 3건(시드 20261009)의 D+63·MA10·MA50을 파이썬 루프로 다시 계산 — 다르면 하드 실패. |

**판정식(기계적)**: A·C nv ≥ 100 아니면 판정 불가. 그 위에서 ① A EV ≥ 0.15R ② A−C z ≥ 2.69 ③ 전반·후반 각각 A ≥ 0.15R 그리고 A > C — 셋 다
참이면 통과, 아니면 기각.

## §1-확인. 해석 기본값 — 실행 전 사용자 확인 대기

1. **통과** → 관찰에 "좋은 되돌림" 진입 후보 표시, 실전은 별도 결정(원문). 관찰 화면에 분봉 반응(④ 원래 정의)을 기록하는 건 별도 작업.
2. **기각** → 종결(원문).
3. **판정 불가** → 앞으로 쌓이는 건으로(원문).
4. **매물대 기준가**: ABC 함수의 "현재가"를 **기준봉 전일 종가**로 둔다(원문 "기준봉 전일까지의 데이터") → 매물대 = 전일 종가 위쪽 최대 거래량
   구간(기준봉이 뚫고 올라간 매물). 매물대가 없으면(전일 종가 위에 거래량 있는 구간 없음) 미진입. 매물대가 기준봉 종가보다 위면 첫날부터
   종가 < 하단이라 이탈로 미진입된다.
5. **매물대 창**: 함수 기본값 그대로 최근 250봉 — 이력이 그보다 짧으면 있는 만큼(99일선은 100~249봉일 수 있다).
6. **③ "닿음"** = 그날 **저가가** [min(MA10, MA50), max] 안(원문 문자 그대로). 대안: 봉 범위가 구간과 겹침(저가 ≤ max 그리고 고가 ≥ min).
7. **②·③·눌림의 시점**: 기준봉 다음 날부터 어느 날이든 충족하면 된다(눌림 시작 전 날이어도, 순서 무관). 확인봉은 셋이 모두 충족된 봉의
   **다음 봉부터**(같은 봉은 안 됨).
8. **이탈 감시 기간**: "그때까지" = 확인봉까지. 기준봉 다음 날부터 확인봉(포함)까지 매일 종가 < 매물대 하단·종가 < MA50을 본다(닿기 전에도).
9. **손절** = 기준봉 다음 날~확인봉(포함) 최저 저가.
10. **겹침(G6)**: 포지션 기간 안의 기준봉, 또는 진입봉이 포지션 기간 안에 들어가는 이벤트를 건너뛴다. 확인 대기 중인 기준봉끼리는 서로 막지 않는다.
11. **저유동성**: 확인봉까지 정제 데이터로 판정(진입 시각에 알 수 있는 데이터).
12. **D+63**: 진입봉을 1번째로 세어 63번째 유효봉 종가, 진입가 대비. 최고·최저는 그 63봉의 고가·저가. 63봉이 안 되면 미완으로 따로.
13. **운영 ABC 대조**: 로컬 `analyze_abc`로 대신했다(위 "실행 전 확인").
