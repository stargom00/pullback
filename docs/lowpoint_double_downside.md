# 1년 +100% 특징 종목의 하락 쪽 (측정만)

> 2026-11-24 등록. 계기: docs/lowpoint_double_features.md에서 확인된 두 특징(200일선 38%+ 아래 · 60일 종가 범위 65%+)이 1년 +100% 비율을
> 3배 높였지만 하락 쪽을 재지 않았다고 보고 → 사용자 "첫번째거부터"(하락 쪽 재기).
> 분류: **측정만(판정 없음)** — 같은 표본 전체(발견+확인 1,514신호)의 기술 통계.

## §1. 사전등록 (실행 전 고정)
- 표본·특징·컷: 직전 측정과 같다(사분위 컷 = 그 측정 발견 절반의 컷, 결과 JSON `explore.*.cuts`). 매수 = 신호 다음 첫 시가, 창 250거래일.
- 군: 전체 · F4 좋은 쪽(200일선 대비 ≤ −38.4%) / 나쁜 쪽(> −20.5%) · F7 좋은 쪽(60일 범위 > 65.0%) / 나쁜 쪽(≤ 29.5%) · **둘 다 좋은 쪽** · 둘 다 아님.
- 지표(군마다): 1년 안 +100% 비율 · 최대 낙폭(창 안 최저 저가 ÷ 매수가 − 1) 중앙값 · −30%·−50% 이하로 내려간 비율 · 250일 뒤 종가 수익
  중앙값·평균 · 250일 뒤 손실 비율 · −50% 이하로 끝난 비율 · +100% 도달 전에 −30%를 먼저 찍은 비율(도달 건 중).
- 한계: 상장폐지 종목 없음(하락 쪽이 특히 과소평가된다 — 상장폐지는 −100%).
- 실행 시각: `harness.check_run_window(("kr",))`.

- 해석: 두 특징 군은 두 배 비율이 3~5배 높지만, **−50% 이하를 찍는 비율도 약 3배**(20% vs 6~7%)이고 1년 뒤 −50% 이하로 끝나는 비율도
  3~5배다. 1년 뒤 손실 비율 자체(약 52~55%)는 군끼리 비슷하다. 규칙대로(+100% 매도) 하면 평균·중앙 모두 특징 군이 나았다(사전등록 밖, 판정 아님).
- 한계: 상장폐지 종목 없음 — 하락 쪽(특히 −50% 이하)이 실제보다 작게 나온다. 물타기(−50% 같은 수량 추가)는 넣지 않은 단순 보유 기준.
