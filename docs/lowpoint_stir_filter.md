## §1. 사전등록 (실행 전 고정 — 결과를 본 뒤 조건·문턱을 바꾸지 않는다)

  덜어내기, 비용 0.25%, 최대 250거래일). 11-15 코스닥 5일선 필터 측정과 같은 표본 정의.

  주식·거래 중**(KIND 목록은 이 환경에서 접근 차단 — 11-15와 같은 대체). 관리종목이 섞이고 상장폐지 종목이 없다(생존 편향).

### 1.2 필터 — `scripts/screens/stir_screen.stir_check`(운영 칩과 같은 함수, import)
- 판정 시점: **매수일 직전 거래일까지** 자른 일봉에 `harness.clean_at_checkpoint`(프로덕션 정제) → 마지막 봉 = 신호 주의 마지막
  거래일. 매수 시점에 이미 확정된 값만 쓴다(룩어헤드 없음).
- **통과** = A(지수이평 20 < 60 < 115) and (B 1봉전 5봉 평균거래량 ≥ 55,555주 or C 금일 제외 5일 평균거래대금 ≥ 50백만) and
  D(종가 > 20 지수이평) and E(단순 20·60 간격 ≤ 2%). **미통과** = 판정했고 False. **판정 불가**(116봉 미만 등) = 두 군에서 빼고 수만 기록.
- 지수이평 시작값: 자른 일봉 전체에 ewm(adjust=False). 이력이 짧은 종목은 키움 값과 조금 다를 수 있다(한계로 기록).

### 1.3 결과 지표와 판정 (Bonferroni 3 → z ≥ 2.39)
- **O1(주 지표) 빨리 감** = 20거래일 안 +5% 익절 비율(`system.exit == "target"` and `system.days ≤ 20`). 통과 − 미통과 두 비율 z.
  사용자 질문("언제까지 기다려야")에 직접 대응.
- O2 건당 수익 `system.ret` 평균: 통과 − 미통과 Welch z.
- O3 묶임률(`system.exit == "cap"`, 250일 안 +5% 못 감): 미통과 − 통과 두 비율 z(양수 = 통과가 덜 묶임).
- **채택(표시를 "먼저 볼 종목" 근거로 올림)** = O1 z ≥ 2.39 그리고 시기 반분(매수일 중앙값) 양쪽 비율 차 > 0 그리고 통과 n ≥ 100
  그리고 미통과 n ≥ 100. O2·O3는 같은 문턱으로 따로 표시(채택 조건 아님).
- **역방향** = O1 z ≤ −2.39 그리고 반분 양쪽 < 0 → 칩을 "주의"로 바꿀 근거로 기록.
- 통과 n < 100 → **판단 불가(표본 부족)** — 판정 없이 수만 기록, 조건 완화 재실행 금지. 매매 0건이면 하드 실패.
- 기록만(판정 없음): 군별 +5% 도달 거래일 중앙값, 코스닥·코스피 나눠 본 O1.
