> **상태: 사전등록(2026-10-09). 해석 기본값은 600일선과 같다(사용자 지시로 확정 — §1-확인). 실행 전.**

## §0. 왜 재는가 — 앞 측정들과의 관계

- **2026-10-09 MA99 돌파 후 되돌림 측정(docs/ma99_breakout_retest.md) — 기각.** 그건 바닥형(ABC A 통과) 종목이 직전 20봉 MA99 아래에서
  처음 종가 > MA99(돌파) → 20봉 안 되돌림 지지봉 종가 진입이었다. **이번엔 장대양봉(+15% 양봉) + 99일선 종가 돌파, 다음 날 시가 진입**이고
  대상은 전체 종목이다 — 다른 가설이다.
- 저점 출발 계열 세 측정(+5% 고가 z −8.08 · 기준양봉 다음 날 z −7.33 · 지지 확인 z −6.08) 모두 기각 — 장대양봉 위치 조건이 없었다.
- **다중 검정**: 저점 출발 계열 셋 + 600·99 둘 = 같은 아이디어 다섯 번째 검정 → **Bonferroni 5, z ≥ 2.58**(600일선과 같음).

## §1. 사전등록 원문 (사용자 지시, 2026-10-09 — 그대로 옮김)

```
- 사용자 요청으로 같은 설계를 99일선에도 적용한다. 2026-10-09 MA99 돌파 후 되돌림 측정(기각)과 달리, 이번에는 장대양봉 + 99일선 종가
  돌파다.
- 저점 출발 계열 셋에 600·99 둘을 더해 같은 아이디어의 다섯 번째 검정이므로 Bonferroni 5를 적용한다. 두 가설 모두 z ≥ 2.58.
3. 99일선 측정을 별도 문서로 사전등록한다(docs/ma99_bull_candle_breakout.md, 실행 전 커밋). 등록부에도 행을 추가한다.
   - 600일선 스크립트를 import해서 선 길이만 99로 바꾼다. 나머지(장대양봉 정의, A/C 정의, 진입 = 다음 날 시가, 손절 = 장대양봉 시가 저가
     터치, +2R/60봉, 겹침 건너뛰기, 저유동성, 반분, 해석 기본값 4~9)는 같게 둔다. 이력 기준은 정제 유효봉 100개 이상이다.
   - 판정: A EV ≥ 0.15R, A−C z ≥ 2.58, 반분 양쪽 A ≥ 0.15R 그리고 A > C, A·C nv ≥ 100. A나 C의 nv < 100이면 판정 불가.
   - 해석 기본값은 600일선과 같다(통과 → 진입 후보 표시, 실전은 별도 결정 / 기각 → 종결 / 판정 불가 → 앞으로 쌓이는 건으로).
   - 기록만(판정에 쓰지 않음, 600일선 문서에도 동일 추가): 같은 이벤트가 99·600 둘 다 A인 건수(겹침), 연도별 건수, 그리고 장대양봉 종가
     대비 D+63 종가 변화율을 A·C 각각에 대해 상승·하락 비율, 중앙값, 25%·75% 지점, 구간별 건수(−30% 이하 / −30~−10 / −10~0 / 0~+10 /
     +10~+30 / +30~+100 / +100 이상), 63일 안 최고·최저 % 중앙값으로 보고한다. 63거래일 전에 데이터가 끝나면 따로 집계한다.
4. 두 측정을 차례로 실행한다(600 → 99). 결과를 각각 문서와 등록부에 기록한다.
[테스트] 99일선 사보타주 — 아래 중 하나라도 A로 잡히면 테스트 결함으로 보고 멈춘다. ① 고가로만 99일선을 넘은 장대양봉 ② 전일 이미
  99일선 위였던 장대양봉 ③ +14.99% 양봉의 돌파 ④ 유효봉 99개인 종목. 99일선 수기 대조: 무작위 3종목 × 3날짜.
```

**출처 고지**: 99·1.15·0.15R·2.58·n100·2R/60봉·3,000일·D+63은 사용자 지시 값이다. 웹 검색·백테스트 근거는 없다.

## §1-구현

600일선 문서 §1-구현 M1~M10과 같다. 다른 것은 아래뿐이다.

| # | 항목 | 99일선 |
|---|---|---|
| N1 | 선 | 정제 일봉 종가 단순이동평균 **99**(`ma_at(p, back, 99)`) |
| N2 | 이력 기준 | 장대양봉 봉까지 정제 유효봉 **100개 이상**(전일·당일 MA99) — 99개는 판정 안 함(테스트 고정) |
| N3 | 기록용 비교 선 | 같은 장대양봉이 **600일선 기준으로도 A**인 건수(`classify(p, 600)`, 정제 이력 601봉 미만이면 해당 없음) |
| N4 | MA 수기 대조 | 실행 시작 시 무작위 3종목 × 3날짜(시드 20261009), 파이썬 합 ÷ 99와 대조 — 0.01% 넘게 다르면 하드 실패 |

판정식: A·C 각 nv ≥ 100이 아니면 **판정 불가**. 그 위에서 ① A EV ≥ 0.15R ② A−C z ≥ 2.58 ③ 전반·후반 각각 A EV ≥ 0.15R 그리고 A > C —
셋 다 참이면 **통과**, 아니면 **기각**.
