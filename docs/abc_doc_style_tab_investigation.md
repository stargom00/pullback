# ABC(문서 방식) 탭 조사 기록 — 보류 (2026-08-07)

**결론: 이 형태로는 진행하지 않음.** 매집봉(+15% 일봉) → 돌파(진돌이) → 눌림 재터치
조건이, 같은 날·같은 시총 유니버스에서 무작위로 산 것보다 15% 도달률이
**낮게** 나왔다(선별력 없음 정도가 아니라 방향이 반대). 근거는 이 문서 하단.
같은 아이디어가 다시 나오면 처음부터 재측정하지 말고 이 문서부터 볼 것.

모든 수치는 **백테스트가 아니라 규칙/조건 비교용 근사치**다. 슬리피지·거래비용·
분할매매가 없고 진입가=종가로 단순화했다. 실제 수익률 추정치로 쓰면 안 된다.

## 0. 배경

문서(사용자 제공, 미래에셋벤처 등 사례)의 "A(하락)-B(횡보/매집)-C(600·1000일선
돌파)" 패턴을 KR 시장 전체에서 스캔하는 새 탭으로 설계 시도. 기존 `_pat_abc`
("ABC상한가", 이번 조사와 별개 — 개명 예정: 급등매집)와는 다른 신규 로직.

## 2. 손절/목표 실험 — 전부 폐기

### 시도 순서와 각각 왜 틀렸는지
1. **고정 -5%**: median 손절폭 4.88%, 안 나쁨. 하지만 진입 위치(매집봉 종가 ±2%
   재터치) 자체가 잘못 정의됨 → 재정의.
2. **ATR×mult 손절**(`apply_atr_buffer` 재사용): 폭은 좁아졌지만(median 2.09%@0.3배)
   **손절 발동률이 97~99%**로 사실상 항상 걸림. "타이밍이 B구간과 섞여서"라는
   가설을 세우고 진입을 돌파 이후로 제한해 재측정했으나 발동률 그대로(97%대) —
   **가설 기각**.
3. **R배수 목표(1R/2R/3R)**: ABC는 "15% 갈 종목 찾기"지 R 기반 시스템이 아니라는
   지적으로 폐기, 절대 목표(10/15/20/30%)로 전환.
4. **EV 최적화**(목표% vs 손절 경쟁 시뮬레이션): 목표10%+ATR0.3+종가기준이
   EV +0.80%(최고)로 나왔으나, **손절률 82%인 규칙은 EV가 양수여도 실행 불가**
   (연속 손절 10~20회 구간을 못 버팀, 거래비용 0.3%만 넣어도 음전환)라는 지적.
   **손절률≤60% 제약을 걸면 살아남는 조합이 3~4개뿐이고 전부 EV 음수**
   (예: target10%/ATR2.0: EV -1.62%, 비용 반영 후 -1.92%).
5. **결론**: 손절 구조를 아무리 조정해도 이 진입 정의 자체에서 EV/실행가능성이
   같이 나오는 지점이 없었다. → 손절 문제가 아니라 **선별력 자체를 먼저 검증해야
   한다**는 방향 전환.

## 3. 선별력 검정 — 핵심 결과

### 3.1 1차 시도(모집단 불일치, 무효)
대조군A를 시총필터 없는 기존 유니버스 전체·7.6년 무작위로 재서 49.2% 나왔는데,
실험군(40.7%)보다 높았음 — 그러나 모집단이 다르고(시총필터 유무) 관측기간 전체가
강세장 쪽으로 치우쳐 있어 이 비교 자체가 무효였음(아래 3.3 참고).

### 3.2 2차 시도(모집단 통일 + 시점매칭) — 유효한 비교

| | n | 15% 도달률(60봉) | 95% CI |
|---|---|---|---|
| 실험군(매집+돌파+재터치) | 404 | 40.6% | [35.9, 45.4] |
| 대조군A'(시총필터만, 무작위 시점) | 4866 | 45.1% | [43.7, 46.5] |
| **대조군(시점매칭 — 같은 날, 무작위 종목)** | 284 | **52.1%** | **[46.3, 57.9]** |

실험군 CI 상단(45.4)과 시점매칭 대조군 CI 하단(46.3)이 거의 안 겹침 — 우연으로
보기 어려움. **시점을 완전히 맞춰도 실험군이 무작위보다 낮다.**

### 3.4 최종 검증 — 조건 분리(b) + 진입 타이밍(c) + 30봉 재측정(a)

4개 조건 단계(모두 매집봉 전제, 시점매칭 대조군과 비교):
- **G1**: 매집봉만 (매집봉 다음날 진입)
- **G2**: 매집봉+돌파, 돌파 즉시 진입
- **G3**: 매집봉+돌파+재터치 (원래 실험군)
- **G4**: 매집봉+돌파전 조기 재터치 (돌파 조건 없이 B구간 중 종가 근접 시)

**60봉 창** (실험군 − 시점매칭, %p):

| | n | 실험군 | 매칭대조군 | 격차 |
|---|---|---|---|---|
| G1 매집봉만 | 1118 | 38.0% | 54.4% | **-16.4pp** |
| G2 돌파 즉시 | 509 | 39.1% | 45.9% | -6.8pp |
| G3 재터치(원안) | 404 | 40.1% | 49.3% | -9.2pp |
| G4 돌파전 조기재터치 | 745 | 41.3% | 50.6% | -9.3pp |

**30봉 창** (홀딩기간 단축, 매칭실패도 크게 감소):

| | n | 실험군 | 매칭대조군 | 격차 |
|---|---|---|---|---|
| G1 매집봉만 | 1118 | 32.8% | 33.9% | -1.1pp |
| G2 돌파 즉시 | 509 | 31.6% | 33.8% | -2.2pp |
| G3 재터치(원안) | 404 | 31.7% | 34.0% | -2.3pp |
| G4 돌파전 조기재터치 | 745 | 34.4% | 33.3% | **+1.1pp(유일하게 역전)** |

**해석**:
- 조건을 하나씩 뺄수록(G3→G1) 60봉 격차가 커진다(-9.2pp→-16.4pp) — 조건들이
  완전히 무의미하진 않지만, "무작위를 이긴다"까지는 어느 조합도 못 감.
- 진입을 앞당길수록(G4가 가장 이름) 격차가 줄어들고 30봉에서는 유일하게 양전환
  — "이미 급등+돌파까지 끝나서 여력이 소진된 자리에서 사는 게 문제"라는 가설과
  방향이 일치. 다만 효과 크기가 작고(+1.1pp) CI도 겹쳐서(30봉 데이터는 이 문서에
  CI 미기재, 원본 json 참고) 확정적 신호는 아님.
- **30봉(≈1.5개월)에서는 모든 조건 조합이 무작위와 통계적으로 구분 안 됨.**
  60봉(≈3개월)에서는 오히려 무작위가 우세. 어느 기간으로 봐도 "이 조건이 무작위를
  이긴다"는 근거가 없음.

## 4. 재검토 시 참고할 것

- G4(조기 재터치, 돌파 전)가 다른 조건보다 상대적으로 나은 방향성을 보임 — 만약
  이 아이디어를 다시 살린다면 "돌파를 기다리지 않고 B구간 중 조기 진입"부터
  다시 볼 가치는 있음. 단, 그래도 "무작위를 이긴다"는 강한 신호는 아니었음.
- 시점매칭 대조군 구성법(같은 날짜, 같은 유니버스에서 무작위 종목 추출)과
  Wilson score 95% CI는 앞으로 다른 스캐너 조건을 검증할 때도 재사용 가치 있음.
- 연도별 기준선 도달률 표(3.3)는 KR 시장 자체의 "그냥 아무거나 사도 얼마나
  가는지"이므로, 다른 조건/탭 검증할 때 이 표와 비교하면 모집단·시점 문제를
  처음부터 피할 수 있음.
- 원본 측정 스크립트/JSON은 세션 스크래치패드에 있었음(휘발성) — 재현하려면
  이 문서의 방법론(매집봉 정의, 시총 스캔 로직, 시점매칭 로직)을 그대로 다시
  구현하면 됨. `naver_kr._parse_marketcap_rows`/`_MARKETSUM_URL`,
  `scanner.horizontal_levels`, `scanner.apply_atr_buffer`가 전부 재사용 가능한
  기존 함수임을 확인함.
