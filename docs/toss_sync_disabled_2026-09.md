# 토스 동기화 비활성화 (v5.222, 2026-09-09)

## 상태

`TOSS_SYNC_ENABLED` 플래그(app.py, 기본값 `false`)로 껐다. 코드는 전부
남아있음 — `POST /api/positions/sync`가 유효한 `SYNC_TOKEN`으로 들어온
요청도 `{"ok": true, "disabled": true}`만 돌려주고 positions.json은
안 건드린다(마지막 스냅샷 그대로 유지). 재활성화는 Railway 환경변수
`TOSS_SYNC_ENABLED=true`만 켜면 된다 — 다른 코드 변경 불필요.

## 왜 껐나

1. **Railway는 애초에 토스 Open API를 직접 못 부른다** — 토스가 "허용
   IP"만 받는데, Railway 아웃바운드 IP가 배포·재시작·스케일마다 바뀐다
   (AWS 공유 풀에서 매번 새로 할당, docs/toss_position_sync_setup.md
   원래 아키텍처 노트 그대로). 그래서 지금까지는 맥 로컬에서
   `sync_toss.py`(launchd, 30분 간격)가 대신 조회해 서버로는 수량·평단만
   보내는 우회 구조를 썼다.
2. **그런데 그 우회조차 지금 막혀있다** — 토스 API가 맥에서 직접 호출해도
   403(IP 미허용)을 낸다(`sync_toss.py`가 `client.get_holdings()` 단계에서
   실패 — 이 레포의 `/api/positions/sync` 엔드포인트까지 도달하기도 전).
   등록된 허용 IP와 지금 맥의 공인 IP가 안 맞는 것으로 보임(원인 미확정
   — 가정용 회선 IP가 바뀌었을 수도, 토스 쪽 정책이 바뀌었을 수도 있음).

## Railway 고정 IP 조사 결과 (2026-09-08)

혹시 로컬 우회 대신 Railway에서 직접 부르는 쪽으로 아키텍처를 바꾸면
어떨지 조사했음 — 결론: **가능은 하지만 조건부**.

- Railway가 2026-07부터 **Static Outbound IPs**(Pro 플랜, 워크스페이스
  기준 $20/월)를 새로 냈다. 서비스당 IP **3개**를 로드밸런싱해서 준다
  (완전 전용 보장은 아님 — 다른 고객과 공유될 수 있음, 리전 이동 시 IP
  바뀜).
- **막히는 점**: 토스 오픈API 콘솔의 "허용 IP" 등록이 1개만 받는지 여러
  개/대역을 받는지 이 레포·문서 어디에도 안 나와 있다 — Railway 기본이
  3개짜리 세트라, 토스가 1개만 받는 방식이면 그대로는 못 쓴다. 재검토
  시 이것부터 토스 콘솔에서 직접 확인할 것.
- 대안도 같이 조사함: QuotaGuard Static IP($19~/월, 하위 티어는 마찬가지로
  "공유 IP 쌍" — 완전 전용은 Enterprise $269/월부터) / 소형 VPS 자체
  프록시(월 $4~6, DigitalOcean·Vultr·Hetzner 등 — 진짜 단일·전용 IP,
  대신 서버 하나를 직접 유지보수해야 함).
- 가격만 보면 소형 VPS 프록시가 제일 싸고 단일 IP 보장도 확실하지만,
  이 프로젝트에 Railway Pro의 다른 기능이 필요해지면 Static Outbound
  IPs 쪽이 더 간단할 수 있음.

## 지금 뭘 해야 하나

- **저널 실체결가는 수동 입력으로만.** `entry_source='toss'` 자동채움
  경로(app.py `positions_sync()` 안, [3] 참고)는 코드 그대로 남아있지만
  동기화 자체가 안 도니 지금은 안 돈다 — 저널 UI의 실체결가 직접 입력
  경로([4]UI, docs 기존 설명 참고)로 계속 기록할 것.
- **맥 로컬 launchd도 원하면 같이 꺼둘 것** — 이건 이 레포 코드가 아니라
  사용자 맥의 로컬 설정이라 여기서 대신 못 끔:
  ```bash
  launchctl unload ~/Library/LaunchAgents/com.seulki.pullback.synctoss.plist
  ```
  (`docs/toss_position_sync_setup.md`에 같은 명령 이미 있음). 안 꺼도
  무해함 — 계속 돌아도 토스 API 403에서 매번 조용히 실패만 하고(로그만
  남음), 서버 쪽엔 어차피 `TOSS_SYNC_ENABLED=false`라 아무 영향 없음.
- **UI**: 포지션 탭이 이제 "⚠️ 스냅샷 오래됨"(빨간 경고) 대신
  "🔕 자동 동기화 비활성화"(중립 배지)를 보여준다 — 껐다는 사실 자체가
  문제가 아니므로 매일 뜨는 붉은 경고로 처리하지 않는다(v5.222 [2]).

## 재검토 조건

**실체결 30건이 쌓여서 "자동화할 가치가 확인되면"** 재검토한다(사용자
지시, 2026-09-09). 그 전까지는:
1. 토스 오픈API 콘솔에서 허용 IP 등록 개수 제한 확인(위 "막히는 점")
2. IP 문제가 실제로 뭔지 재확인(맥 IP가 바뀐 건지, 토스 정책이 바뀐
   건지) — 바뀌었으면 그냥 재등록으로 끝날 수도 있음
3. 그래도 안 되면 Railway Static Outbound IPs vs 소형 VPS 프록시 중
   택일해 아키텍처 변경

수동 기록(저널 실체결가 직접 입력)이 쌓이는 대로 그 30건 기준을
자연스럽게 채우게 되므로, 별도 트래킹 장치 없이 저널 통계에서 그때그때
확인하면 됨.
