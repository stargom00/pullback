# KR 종가베팅 전략 백테스트 — 탭 신설 전 검증 (2026-08-29)

> **⚠️ 2026-09-01 발견: base 조건이 표기와 다르다.** "base(거래대금
> 상위100)"은 실제로는 **"KR 전종목이 아니라 `get_universe("kr")`
> 유니버스(~1500종목) 내 거래대금 상위100"**이다. 이 유니버스는 원래
> "거래대금 상위 1500"을 표방하지만, 실측 결과 91%가 시가총액 순위
> 폴백으로 채워지고 있음이 확인됐다(네이버 `sise_quant.naver` 페이지의
> `page` 파라미터가 응답에 반영되지 않는 버그 — 상세는 별도 조사 기록).
> 즉 시총이 작아 이 유니버스 밖에 있는 종목은 당일 거래대금이 실제로
> 크더라도 base 조건을 평가받을 기회조차 없다. 이 문서의 z=4.28도 이
> 왜곡된 모집단 위에서 나온 수치일 가능성이 있다 — **재측정 대기,
> 채택 유지/철회 판정은 재측정 후 확정한다.**

## 배경

"실전 고수 조건"(당일 강한 양봉 + 거래량 폭발 + 유동성 상위 + 이평선
위 + 신고가 근접)을 계량 조건으로 번역해, T일 종가 매수 → T+1일 시가
매도(종가베팅) 전략이 새 탭으로 신설할 만한 엣지가 있는지 사전 등록
백테스트로 검증한다.

## 전략 정의

- **기본 시나리오**: T일 종가 매수 → T+1일 시가 매도.
- **보조 시나리오**: T+1일 고가 매도 — 단, 이 레포가 가진 건 일봉
  (daily OHLC)뿐이라 "오전 고가"가 아니라 **T+1 하루 전체의 고가**로
  근사했다(장중 타임스탬프 데이터 없음 — 한계로 명시, 실제 오전 매도가
  이보다 낮을 수 있어 참고용 상한치로만 본다).

## 후보 조건

| 조건 | 정의 |
|---|---|
| base | 당일(T) 거래대금(종가×거래량) KR 전종목 상위 100 이내 |
| candle | 당일 등락률 +3%↑ & 종가가 당일 고가 대비 -2% 이내(윗꼬리 짧음) |
| volume | 당일 거래량이 직전 20거래일(T 제외) 평균 대비 2배 이상 |
| position | 종가 > 20일 이동평균 & 52주 고가 대비 -15% 이내(`scanner.off_high_pct()` 재사용) |
| theme | **측정 불가로 제외** — 아래 "theme 조건 제외 사유" 참고 |

### theme 조건 제외 사유

`money_flow_data/kr/`에 스냅샷이 **2026-08-26 단 하루치만** 존재
(2026-08-29 확인, `ls` 직접 확인). 사용자가 명시한 "데이터 있는
기간만" 조건을 그대로 적용하면 usable 기간이 사실상 0일이라
백테스트 자체가 성립하지 않는다 — 추정치로 채우지 않고 조건에서
완전히 뺐다(CLAUDE.md "백테스트 없는 승률 주장 금지" 원칙).

## 방법론

- **체크포인트**: `checkpoints(60,250,10)` 20개 — 세션 전체 공용 표준.
- **데이터**: harness 기본 KR fetch(730일, ≈490거래일)는 off=250 +
  52주(252봉) lookback을 감당 못 해(250+252=502 > 490) 이 스크립트만
  `naver_kr.fetch_history(ticker, days=1100)`(≈730거래일, 실측 731봉)로
  직접 fetch — harness.py는 확장 안 함(이 백테스트 전용 요구사항).
- **비용**: 왕복 수수료+슬리피지 0.3%(사용자 지시) 차감 후 수익률을
  "비용차감후"로 표시.
- **z검정**: `harness.ev_gap_zscore`는 -1/0/+2R 이산분포 전용 공식
  (README 규칙7)이라 이 연속형 % 수익률엔 안 맞아, 표준 2표본 평균차
  z검정(표본분산 기반)을 이 스크립트에 새로 작성 — 재구현이 아니라
  애초에 다른 데이터 타입에 맞는 통상 공식.
- **규칙6**(대조군 유동성매칭): 대조군 자체가 base(거래대금 상위100)라
  그대로 충족.
- **규칙8**(KR/US 미혼합): KR 단일 시장만 다뤄 해당 없음.

근거 스크립트: `scripts/measurements/2026-08-29_kr_jongga_betting_backtest.py`.

## 사전 등록 판정 기준

최종 조합(base+candle+volume+position)이 **(a)** 비용차감후 평균갭
+0.5% 이상 **그리고** **(b)** 이전·최근 절반 둘 다 비용차감후 평균갭
+0.5% 이상 **그리고** **(c)** 대조군(base) 대비 z≥1.96로 유의 우위 —
셋 다 충족해야 탭 신설 진행. 하나라도 미달이면 조건 재설계 또는 보류.

### 대조군(base) 대비 유의성

base 평균갭 +0.49%(n=1,884) vs 최종조합 평균갭 +1.94%(n=70) — 격차
**+1.45%p, z=1.84**. 사전 기준(z≥1.96)에 **살짝 못 미친다**(양측 95%
문턱 바로 아래) — `docs/maejip_candle_filter_kr.md`의 has_maejip
z=1.94 사례와 같은 유형의 "경계선 근접"이다. 표본이 작아서
(최종조합 n=70) 검정력 자체가 낮다는 점이 큰 원인 — 효과 크기(+1.45%p)
자체는 base 평균의 3배에 가까운 큰 폭이다.

## 판정 — 사전 기준 미달(경계선), 보류

**(a) 충족(+1.64% ≥ +0.5%), (b) 충족(두 절반 다 재현), (c) 미달
(z=1.84 < 1.96) — 셋 다 충족을 요구한 사전 기준상 최종 판정은
"조건 재설계 또는 보류".** 세 기준 중 하나가 근소하게 미달이라고
바로 확대해석해 채택하지 않는다 — 사전 등록의 취지 자체가 사후에
기준을 낮춰 끼워맞추는 걸 막는 것.

다만 완전한 무신호와는 다르다: 효과 크기가 크고(base 대비 +1.45%p,
약 3배) 시간 반분도 재현됐다 — z=1.84는 "우연과 완전히 구분 안 됨"
(has_maejip z=1.94와 마찬가지로 절대 기각권이 아니라 표본 부족형
미달)에 가깝다. **다음 단계 후보**: 조건을 유지한 채 표본을 늘려
재현 확인(다른 실행일/체크포인트 밀도 확대) — has_maejip 사례에서
표본을 늘려 재검증했던 것과 동일한 절차. 이번 라운드에서는 탭 신설
보류, scanner.py/app.py/static 미변경.

  신호로 보인다. base/volume이 candle보다 단독 성능이 좋다는 점도
  같은 방향.

### 배경 — 원측정 진단 반영

원측정의 미달 원인 진단: ① candle 조건이 단독으로는 역효과로 확인,
② 최종조합 n=70으로 검정력 부족(z=1.84, 기준 1.96 근소 미달). 이
두 진단을 반영해 **1회만** 재설계한다 — 이후 조건을 더 바꾸지 않고
표본(실행일) 축적으로만 재검증한다(사전 등록 취지 보호, 사후

### 사전 등록

**① n 확보 — 데이터 기간 가용 최대 확장**: `naver_kr.fetch_history()`
는 요청 기간 실질 상한이 없는 것으로 이미 확인돼 있고
(`docs/abc_doc_style_tab_investigation.md`에서 1900일(≈1275봉) fetch
성공 전례, 730→1900일 회귀 0건 확인), 이 스크립트도 `days=1900`으로

체크포인트를 원측정 60~250(20개)에서 **60~950(90개, 10 간격 — 원측정
대비 4.5배)** 로 확장.

**② 후보 조합 2개 사전 고정**:
- (A) 원조합 재측정: base+candle+volume+position(조건 정의 동일,
  기간·체크포인트만 확장).
- (B) candle 제외: base+volume+position.

**판정 기준(원측정과 동일, 두 조합에 각각 적용)**: (a) 비용차감후
평균갭 +0.5%↑ AND (b) 이전·최근 절반 둘 다 재현 AND (c) 대조군(base)
대비 z≥1.96 — 셋 다 충족하는 조합이 하나라도 있으면 채택. 둘 다
미달이면 보류 확정 + theme 조건 포함 재측정 예약.

근거 스크립트:
`scripts/measurements/2026-08-29_kr_jongga_betting_backtest_extended.py`.

### 결과

전체 평가 121,698건(원측정 28,600건의 4.3배), base 통과 8,323건.

| 조합 | n | 평균갭 | 비용차감후 | 이전 절반 | 최근 절반 | base 대비 z |
|---|---|---|---|---|---|---|
| **(A) 원조합(+candle)** | 276 | +1.52% | **+1.22%** | +0.96%(재현) | +1.47%(재현) | **4.28(유의)** |
| (B) candle 제외 | 1,102 | +0.65% | +0.35% | +0.38%(미달) | +0.33%(미달) | 2.50(유의) |

**조합 A — 3개 기준 전부 충족.** n=70→276(4배)로 늘자 base 대비
z가 1.84→**4.28**로 크게 뛰었다 — 원측정의 미달이 진짜 무신호가
아니라 표본 부족 문제였다는 진단이 맞았다. 시간 반분도 양쪽 다
+0.5% 기준을 넘어 재현됨.

**조합 B — n은 4배 늘었지만(1,102) 기준 미달.** base 대비 격차는
유의하지만(z=2.50) 크기가 작고(+0.35%), 시간 반분에서 두 절반 다
+0.5% 문턱을 못 넘었다. **candle 조건을 빼면 오히려 최종 조합
성능이 떨어진다** — 원측정에서 candle이 "단독으로는" 역효과였던 것과
별개로, base+volume+position과 **결합**했을 때는 candle이 신호를
더 선명하게 만드는 필터 역할을 한다는 뜻(단독 성능과 결합 성능이
다를 수 있다는 흔한 패턴 — 개별 항목의 단독 방향만으로 조합에서의
역할을 예단하면 안 된다는 교훈).

### 판정 — 채택(조합 A): 탭 신설 진행 검토 대상

**조합 A가 사전 등록 기준 3개 전부 충족 → 채택(단, 2026-09-01 상단 경고
참고 — base 정의 재검증 대기).** 최종 조건:
**base(시총상위 유니버스 내 거래대금 상위100 — "전체 거래대금 상위100"
아님) + candle(+3%↑ 양봉·짧은윗꼬리) +
volume(20일평균 2배+) + position(20일선 위·52주고점-15%이내)**,
T일 종가 매수 → T+1일 시가 매도, 비용차감후 평균 +1.22%(n=276,
