## §1. 사전등록 (실행 전 고정 — 결과를 본 뒤 조건·문턱을 바꾸지 않는다)

### 1.1 표본과 기준선
- 신호·기준선 매매 = `2026-11-10_lowpoint_system_expectancy_listing.py`의 trades(주봉 저점 신호 → 다음 첫 시가 매수, 갭 +5% 제외,
  사용자 규칙 전체 — +5% 전량 익절·−50% 같은 수량 추가·평단에서 추가분 덜어내기·매도비용 0.25%·250거래일). 같은 캐시로 재실행한 결과 사용.
- 데이터: naver 통합 일봉 1,900일(2026-11-23 KST 05시대 수신, KR 마지막 봉 11-20). 유니버스 = naver 시총 목록(KIND 차단 — 생존 편향).
- 표본 제한: ① **상장 1년**(사용자 조건) = 신호 봉까지 정제 일봉 ≥ 250봉 ② 신호 뒤 트리거 창 120봉 + 보유 250봉이 다 있는 신호만
  (최근 신호는 모든 후보에서 빠짐 — 트리거가 늦은 매매만 빠지는 시기 치우침 방지) ③ 무효봉(naver 무거래일 오염)이 있는 종목은 제외(수 기록).

### 1.2 후보 진입 (신호 다음 봉부터 120거래일 안의 **첫** 트리거 → 다음 날 시가 매수, 시가 ≥ 트리거 종가×1.05면 제외)
판정은 그날까지의 봉만 본다. 같은 종목·후보·트리거 날을 가리키는 신호가 둘이면 앞 신호만.

| 후보 | 트리거 |
|---|---|
| A 저점 높이기 | 신호 뒤 2차 저점(앞뒤 3봉 최저 종가, 오른쪽 3봉 확정) 종가 > 1차 저점(신호 포함 직전 20봉 ~ 2차 저점 5봉 전 최저 종가), 2차 저점 뒤 종가가 그 아래로 안 내려간 채 첫 양봉 |
| B 다이버전스 | `divergence.bull_div`(v5.399 칩과 같은 함수) 확정 저점이 신호 뒤 → 첫 양봉 |
| C 조용한 20일선 돌파 | 신호 13거래일 뒤부터, 종가가 단순 20일선을 아래→위로 넘은 날, 그날 거래량 < 직전 20일 평균 × 2 |
| D 역배열 → 정배열 | 신호일 단순 5 < 20 < 60(아니면 D에서 제외), 이후 5 > 20 > 60이 처음 성립한 날 |
| E 600일선 강돌파 | ABC 탭 강돌파 그대로(`abc_screener._find_gate_break`: 600일선 첫 종가 돌파 · 당일 +7% · 거래량 50일 평균 2배) |

숫자 출처: E는 ABC_CONFIG(사용자 확정 50일 평균 포함, 나머지는 그 파일에 적힌 대로 임의값). A의 3봉·20봉, C의 13일(11-14 탐색
"바닥 후 12일 이하 실패↑")·2배, D의 5·20·60, 창 120일은 **AI(Claude) 어림값 — 측정·웹 근거 없음**.

### 1.3 결과 지표와 판정 (짝 비교: 같은 신호의 후보 매매 − 신호 직후 매매)
- **O1(주) 빨리 감** = 20거래일 안 +5% 익절 여부. 짝 차이 평균의 z(짝 t).
- O2 건당 수익(`system.ret`) 짝 차이 z. O3 묶임(250일 안 +5% 못 감) 짝 차이 z(양수 = 후보가 덜 묶임).
- **Bonferroni 5 → |z| ≥ 2.58.** 채택 = O1 z ≥ 2.58 · 시기 반분(신호일 중앙값) 양쪽 O1 차 > 0 · 짝 n ≥ 100.
  역방향 = O1 z ≤ −2.58 · 반분 양쪽 < 0. 짝 n < 100 → 판단 불가(표본 부족), 조건 완화 재실행 금지. O2·O3는 같은 문턱으로 표시만.
- 기록만: 트리거 비율, 신호 뒤 대기 거래일 중앙값, 후보 매수가 vs 신호 직후 매수가(%), +5% 도달 거래일 중앙값.
