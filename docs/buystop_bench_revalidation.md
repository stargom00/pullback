### 1.2 원래 판정 기준 — 5번과 동일함을 확인했고 그대로 재적용

원래 스크립트의 `judge_d()`/`half_split()`/`run_variants()`를 **import해서 그대로 호출한다**
(재구현 없음). 확인 결과 **5번(`_entry_close`)과 판정 기준이 같다** — 상수도 같은 값이다
(`MIN_N_FOR_JUDGMENT = 100`, `EV_GAP_THRESHOLD = 0.15`):

1. `안D_buystop` nv ≥ 100
2. `안D_buystop` EV ≥ +0.15R (절대 EV)
3. `harness.ev_gap_zscore(안A_전체, 안D_buystop)`의 |z| ≥ 1.96
4. 시기반분: `mid_off = OFFSETS[45]`=510 기준 초반(off ≤ 510, 46개)/후반(44개), 각 반기
   히트 ≥100이고 **두 반기 모두 안D EV ≥ 0.15R**

**판정 대상은 KR 5탭의 안D**다(원래 스크립트가 안D를 주 가설로 판정). 안C'(종가진입+확인일
저가손절)와 dedup z, 슬리피지 0.3% 변형은 원래도 참고 병기였고 이번에도 판정에 쓰지 않는다.
조건을 새로 더하지도, 빼지도 않는다.

### 1.3 원래 결과와 사전 예상 (사용자 지시로 예상을 기록, 판정에는 안 씀)

**원래 결과(2026-09-04 실행, KR 안D)**:

| 탭 | 안D EV(nv) | 체결율 | z(vs 안A) | 판정 |
|---|---|---|---|---|
| 눌림목 | +0.071R (2,211) | 64.2% | 0.55 | 미달 |
| **돌파임박** | **−0.099R (5,196)** | 64.4% | **−6.22** | 미달(유의하게 나쁨) |
| 박스돌파 | +0.205R (722) | 67.2% | 1.15 | 미달(z) |
| 돌파 | +0.193R (836) | 69.1% | 1.79 | 미달(z) |
| 추세전환 | +0.068R (1,431) | 61.0% | 0.67 | 미달 |

**사전 예상: 5탭 모두 미달 유지.** 근거:
- 돌파임박은 z −6.22로 **기준선(1.96)에서 반대 방향으로 멀다** — 부호를 뒤집고 유의성까지
  얻으려면 벤치마크 수정이 EV를 0.25R 넘게 밀어야 한다. 2번 재검증에서 벤치마크 수정의
  실측 효과는 gap +0.007R이었다.
- 박스돌파·돌파는 EV가 문턱(0.15)을 넘지만 z가 1.15/1.79로 미달이고, 표본이 상대적으로
  작아(722/836) 벤치마크 수정으로 표본이 재구성되면 어느 쪽으로든 흔들릴 수는 있다 —
  **5탭 중 뒤집힐 가능성이 그나마 있는 건 돌파(z 1.79)** 하나다.
- 이 예상은 기록일 뿐 판정에 쓰지 않는다. 빗나가면 예상이 틀린 것으로 적는다.

### 1.4 실행 설계 — 5번·2번과 같은 4-run 구조

| 실행 | 정의 | 차이가 보여주는 것 |
|---|---|---|
| **R0 원본 복제** | 원본 코드 그대로 + 오염된 벤치마크(900일 + 옛 폴백) 의도적 재현 | R0 − 원래(09-04 발표값) = 데이터 변동 |
| **R1 벤치마크만 수정** | 벤치마크만 `harness.bench_score_at_date`(1900일, 날짜 기준) | R1 − R0 = **순수 오염 효과** |
| **R2 + 시총 필터** | R1 + KR 시총 1000억 추정 필터(RS 계산 전, KR만) | R2 − R1 = 순수 필터 효과 |
| R3 참고 | R2 + 프로덕션 데이터 경로(730일 창 + `clean_at_checkpoint` + 날짜 기준 truncate) | 판정에 쓰지 않음 |

**원본 실행일(2026-09-04)에 맞추기**(5번과 동일 방식):
- `Δ_kr` = KOSPI 캘린더에서 2026-09-04 이후 봉 수. 실제 offset = 원본 offset + Δ_kr.
  이 측정은 **KR만 판정**하지만 원본이 US도 같이 수집했으므로 US도 함께 돌린다(참고 표 유지) —
  US는 `Δ_us`(US 거래일 수)로 따로 계산하고 assert한다.
- fetch 시작일도 맞춘다: `kr_days = 1900 + Δd`, R0 벤치마크 `days = 900 + Δd`, US `5y`.
- **미래 구간은 2026-09-04까지만** 잘라 쓴다(원본이 본 정보 집합과 동일).
- 유니버스: KR은 `kr_universe_v6_1500_20260904_eod.json` + 정적 `KR_UNIVERSE` + 워치리스트
  (5번에서 이 구성이 09-04 프로덕션 히트를 39/39 재현한 것을 확인했다). US는 현재
  `get_universe("us")` — US 유니버스 코드 파일은 09-04 이후 변경 없음(6~7월이 마지막, git 확인).
- R0의 오염 재현은 5번 스크립트의 `_legacy_bench_score_at_CONTAMINATED`를 import해 재사용.
  R1~R3가 그 함수를 호출하지 않았음을 assert한다.
- **R3 주의(2번에서 실제로 터진 버그)**: R3는 종목을 날짜 기준으로 자르므로 **미래 구간도
  날짜 기준**으로 잡아야 한다(offset 기준으로 잡으면 봉이 빠진 종목에서 미래가 체크포인트보다
  앞서고, 룩어헤드 assert가 걸린다 — `docs/super_filter_bench_revalidation.md` §1-부록).

### 1.5 판정 (재량 판단 금지)

- **R0 재현 게이트(±2%)**: R0의 KR 안D nv가 원본(눌림목 2,211 / 돌파임박 5,196 /
  박스돌파 722 / 돌파 836 / 추세전환 1,431)과 **탭별로 ±2% 이내**여야 판정을 진행한다.
  벗어나면 멈추고 원인을 보고한다(판정 없음).
- **판정 실행 = R1과 R2 둘 다.** 어떤 탭이 **두 실행 모두에서** 1.2의 네 조건을 전부
  통과하면 그 탭은 "안D 유효"로 뒤집힌 것 → **채택이 아니라 "복원 후보"로 기록하고 별도
  사전등록**(이 측정으로 UI·GUIDE를 바꾸지 않는다).
- **R1 또는 R2 중 하나라도** 조건을 하나라도 못 넘으면 그 탭은 **미달 유지**.
- R0·R3는 보고만 한다.
- **"피벗 장중 매수 금지" 문구의 근거 유지 여부 — 세 갈래를 결과 보기 전에 확정한다
  (사용자 지시, 재량 판단 금지).** 기준은 **R1과 R2 두 실행 모두의 돌파임박 안D z**로 본다
  (한 실행이라도 다른 갈래면 더 보수적인 쪽 = 위쪽 갈래를 적용):
  1. **z ≤ −1.96 유지** → **금지 문구 유지.** 수치 인용은 새 값으로 갱신 검토(EV 인용 규칙에
     따라 "유의하게 나쁨" 중심으로 서술).
  2. **z가 −1.96 위로 올라옴(유의하게 나쁘지는 않음)** → 금지 문구의 **"z=−6.22" 인용 제거**.
     "금지"를 "권장 안 함"으로 완화할지는 **별도 사전등록**(이번 측정으로 바꾸지 않는다).
  3. **z가 양수로 넘어감** → **금지 문구 자체를 철회 검토**, 역시 **별도 사전등록**. 양수라는
     사실이 "장중 매수가 좋다"는 근거는 아님을 명시한다(채택 판단은 1.2의 네 조건으로만).
  세 갈래 모두 이번 측정에서는 **기록만** 하고 UI·GUIDE는 건드리지 않는다.

### 1.6 보고 형식

1. **5탭 × {원래(09-04), R0, R1, R2, R3}** 표 — 안D EV(nv), z, 체결율, 초반/후반 EV, 판정.
   판정이 바뀐 셀 표시.
2. **변화 분해**(돌파임박·돌파 두 탭 중심): EV와 z가 원래→R0(데이터 변동), R0→R1(**벤치마크
   오염 효과**), R1→R2(시총 필터)에서 각각 얼마나 움직였는지.
3. **해석 규칙(미리 정함)**: 5번·2번과 동일 — R0 미달 & R1 미달 → "원래 미달 판정은
   벤치마크 오염과 무관"; R0 미달인데 R1 통과 → "원래 미달은 오염 탓"; R0부터 원래와 다르면
   "데이터 변동에 민감"으로 기록하고 판정은 R1/R2로.
4. 진단값: R0 재현율(탭별 nv), 벤치마크 폴백 체크포인트 수, 시총 필터 탈락 수, 안C'·dedup·
   슬리피지 변형(참고), 체결율 변화.
5. **EV 인용은 `docs/kr_us_strategy_map.md` "측정 규칙 — EV 절대값 인용 한계"를 따른다** —
   부호·유의성·대략적 크기까지만 단정하고, 세 자리 수치는 측정일과 스크립트를 같이 적는다.

### 1.7 룩어헤드 방지 — assert

- R1~R3: 벤치마크를 cp_date까지 자르고 마지막 날짜 == cp_date, 길이 ≥ 253(`bench_score_at_date`가 강제).
- 전 실행: 미래 구간 첫 날짜 > 체크포인트 날짜, 마지막 날짜 ≤ 2026-09-04.
- 원본 `find_buystop_fill()`/`find_confirm_close()`의 기존 assert(k ≤ 3, 미래 봉 범위) 그대로.
- R1~R3가 오염 재현 함수를 호출하지 않았음을 카운터로 assert.
- Δ_kr/Δ_us 계산 후 `cal[-(60+Δ_kr+1)]`이 2026-09-04 기준 60봉 전 날짜와 같은지 assert.

### 1.8 알려진 한계 (실행 전 선언)

- **유니버스 드리프트**: KR은 2026-09-04 유니버스를 4년 전 체크포인트까지 그대로 쓴다(원본도 동일).
- **EV 절대값 재현성**: 2번 재검증에서 9일 사이 데이터 변동만으로 EV가 ±0.01R 이상 움직였고,
  그 폭이 벤치마크 수정 효과의 3배였다. 이 측정도 R0가 원본 EV를 그대로 재현하지 못할 수
  있다 — 그래서 재현 게이트를 EV가 아니라 **nv(표본 수)**로 잡았다.
- **안D는 장중 체결 가정**이다: "신호 후 3거래일 내 첫 고가 ≥ 피벗인 날 그 가격에 체결,
  그날 저가 ≤ 손절이면 같은 날 손절"(원본 정의). 장중 순서를 알 수 없어 손절을 우선 가정한
  보수적 처리이며, 이번에도 그대로 둔다.
- 시총 필터는 KR에만 적용(프로덕션과 동일).

## §3. 승인 전 확인사항 → 확정 (2026-09-12 사용자 답변)

1. **판정 대상 = KR 안D 5탭 전부.** 뒤집힌 탭(예: 돌파 z 1.79)이 있어도 **복원 후보로만
   기록**하고 채택은 별도 사전등록.
2. **돌파임박 z의 부호·유의성은 별도 항목으로 보고**하고, 1.5의 세 갈래 판정을 그대로 적용.
3. 안C'·dedup·슬리피지 변형은 참고 병기만, 판정에 쓰지 않음.
