## §0. 앞의 세 기각과 이 가설의 차이 (명시)

같은 아이디어(저점 뒤 장대양봉 출발 진입)의 앞선 세 측정은 모두 기각됐다:

| # | 측정 | 대상 | 출발·진입 | 결과 |
|---|---|---|---|---|
| 1 | docs/lowpoint_departure_rest_entry.md | 저점 주봉 히트 코호트 | 고가 ≥ 기준가×1.05 → 다음 날 종가 | **기각**: z −8.08 |
| 2 | docs/bull_candle_departure_entry.md | 같음 | 장대양봉(+15% 양봉) → 다음 날 종가 | **기각**: z −7.33 |
| 3 | docs/bull_candle_support_entry.md | 같음 | 장대양봉 → 눌림 → 지지 확인 → 다음 날 시가 | **기각**: z −6.08 |

- **근거(사용자, 원문 요지)**: "장대양봉 위치 조건이 없어서 하락 도중 급등과 바닥 후 장기선 돌파가 섞여 있었다. 의미 있는 장대양봉은 하락이
  끝나고 횡보한 뒤 장기 이평선을 돌파하는 봉이다. 기간은 종목마다 달라 조건으로 두지 않는다. 99일선은 이미 쟀으니 600일선으로 간다.
  돌파 = 종가가 선 위에 마감한 날."
- **차이**: ① 대상이 저점 스캐너 코호트가 아니라 **전체 종목**이다(KIND 코스피+코스닥 − 관리종목). ② 장대양봉에 **위치 조건**(전일 600일선
  아래 → 당일 종가가 선 위)을 붙였다. ③ 대조군 C가 "같은 코호트의 미출발 종목"이 아니라 **선 아래에서 끝난 장대양봉(하락 중 급등)**이다.
- **다중 검정**: 별개 가설이지만 같은 아이디어 네 번째라 **z 문턱 2.50**(사용자 지정, 보수적).

## §1. 사전등록 원문 (사용자 지시, 2026-10-09 — 그대로 옮김)

```
1. docs/measurement_registry.md에 "600일선 돌파 장대양봉 vs 하락 중 장대양봉"을 사전등록한다(실행 전 커밋). 문서에 앞의 세 기각과
   이 가설의 차이를 명시한다.
   - 유니버스: KIND 상장 종목에서 관리종목 제외(이전 측정과 같음). 600일선 계산이 가능한 봉만 쓴다(유효봉 600개 이상). 저유동성 컷과
     CleanView 정제는 이전과 같다.
   - 600일선 = naver 일봉(공식 종가) 기준 단순이동평균 600.
   - 장대양봉: 종가 ≥ 전일 종가 × 1.15 그리고 종가 > 시가(기준양봉 측정 정의 import).
   - A군: 장대양봉이면서 전일 종가 < 전일 600일선, 당일 종가 > 당일 600일선.
   - C군: 장대양봉이면서 전일 종가 < 전일 600일선, 당일 종가 ≤ 당일 600일선(하락 도중 장대양봉).
   - 진입: A·C 모두 장대양봉 다음 날 시가.
   - 손절 = 장대양봉 시가(저가 터치 = −1R). 1R = 진입가 − 장대양봉 시가. 진입가 ≤ 장대양봉 시가면 제외.
   - 목표·보유 기간은 이전 측정 규칙(+2R / 60봉)을 그대로 쓴다.
   - 같은 종목에서 A·C 이벤트가 겹치면 진입 중인 동안의 새 이벤트는 건너뛴다.
   - 판정: A EV ≥ 0.15R, A−C z ≥ 2.50, 반분 양쪽 A ≥ 0.15R 그리고 A > C, A·C nv ≥ 100.
   - A nv < 100이면 기각이 아니라 "판정 불가"로 기록한다.
   - 기록만(판정에 쓰지 않음): A·C 연도별 건수, 돌파 전 600일선 아래에 있던 기간 분포, 손절폭(1R%) 분포.
   - 해석 기본값(실행 전에 나에게 확인받을 것):
     · 통과 → 관찰에 "600일선 돌파 장대양봉" 표시를 진입 후보로 올리고, 실전 적용은 별도로 결정.
     · 미달 → 600일선 돌파 장대양봉 다음 날 진입은 종결. 구름 돌파는 별도 가설로 따로 검토.
     · 판정 불가 → 앞으로 쌓이는 건으로만 본다.
[테스트] 사보타주 — 아래 중 하나라도 A로 잡히면 테스트 결함으로 보고 멈춘다. ① 600일선을 종가가 아니라 고가로만 넘은 장대양봉
  ② 전일 이미 600일선 위였던 장대양봉 ③ +14.9% 양봉의 600일선 돌파 ④ 유효봉이 599개뿐인 종목. 반대로 전일 종가 < 600선이고 당일
  +15% 양봉 종가 > 600선인 경우는 A로 잡혀야 한다. 600일선 값은 무작위 3종목 3날짜에 대해 수기 계산과 대조한다.
  check_run_window(["KR"]) 통과를 확인한다.
```

**출처 고지**: 600·1.15·0.15R·2.50·n100·2R/60봉은 사용자 지시 값이다(위 원문·이전 측정 규칙). 웹 검색·백테스트 근거는 없다.

## §1-구현

| # | 항목 | 정의 |
|---|---|---|
| M1 | 데이터·유니버스·저유동성 | 저점 출발 스크립트의 `load_data`(KIND 코스피+코스닥 − 관리종목, naver 일봉 1,900일)·`liquid`(harness 표준 컷)를 import. |
| M2 | 정제·MA600 | 각 후보 봉까지 자르고 정제한 df(`CleanView.prefix`)의 종가 600개 단순평균(`ma_at`). 무효봉(OHLC=0 등)은 600개에 넣지 않는다. 이력 부족이면 하드 실패(부분 창 평균 금지). |
| M3 | 장대양봉 | 기준양봉 스크립트의 `is_bull_candle`(종가 ≥ 정제 df 직전 봉 종가 × 1.15 그리고 종가 > 시가). |
| M4 | A / C | 전일 종가 < 전일 MA600 이면서 당일 종가 > 당일 MA600 → A, ≤ → C. 전일 종가 ≥ 전일 MA600이면 둘 다 아님. |
| M5 | 진입·청산 | 장대양봉 다음 유효봉 시가 진입, 손절 = 장대양봉 시가, `harness.race`(진입봉 포함, 저가 ≤ 손절 −1R · 고가 ≥ 2R · 60봉, 같은 날 손절 우선). 진입가 ≤ 장대양봉 시가면 제외. |
| M6 | 겹침 | 종목마다 A·C 이벤트를 시간순으로 보고, 포지션 보유 기간(진입일~청산일 포함 — 손절·목표 봉, 60봉 만료, 데이터 끝) 안에 나온 장대양봉 이벤트는 건너뛴다. 청산 봉은 `harness.race`를 앞 n봉으로 잘라 처음 결론 나는 n으로 찾는다(재구현 아님). |
| M7 | 판정 z | `harness.ev_gap_zscore(C, A)`, 단측 z ≥ **2.50**. 반분 = A 진입일 중앙값으로 A·C 모두 나눔. |
| M8 | MA600 대조 | 실행 시작 시 무작위(시드 20261009) 3종목 × 3날짜, 파이썬 합 ÷ 600과 대조 — 0.01% 넘게 다르면 하드 실패. |
| M9 | 기록 전용 | 진입 연도별 A·C 건수, 돌파 전 MA600 아래 연속 유효봉 수 분포, 1R%(진입 대비 손절폭) 분포, 건너뛴 이벤트 수. |

**판정식(기계적)**: A·C 각 nv ≥ 100이 아니면 **판정 불가**. 그 위에서 ① A EV ≥ 0.15R ② A−C z ≥ 2.50 ③ 전반·후반 각각 A EV ≥ 0.15R
그리고 A > C — 셋 다 참이면 **통과**, 하나라도 거짓이면 **기각**.

## §1-확인. 해석 기본값 — 실행 전 사용자 확인 대기

1. **통과** → 관찰에 "600일선 돌파 장대양봉" 표시를 진입 후보로 올리고, 실전 적용은 별도로 결정(원문).
2. **미달(기각)** → 600일선 돌파 장대양봉 다음 날 진입은 종결. 구름 돌파는 별도 가설로 따로 검토(원문).
3. **판정 불가** → 앞으로 쌓이는 건으로만 본다(원문).
4. **이력 기준**: 원문 "유효봉 600개 이상" — 전일 MA600과 당일 MA600이 둘 다 필요해서 장대양봉 봉까지 **정제 유효봉 601개 이상**으로 둔다
   (599·600개 → 판정 안 함, 테스트로 고정).
5. **C nv < 100**도 판정 불가로 본다(원문은 A만 언급 — 비교 대상이 부족하면 기각할 근거도 없다).
6. **겹침 규칙(M6)**: A·C 구분 없이 같은 종목의 포지션 기간 안 이벤트를 건너뛴다. 저유동성·진입가 ≤ 손절로 **제외된 이벤트는 포지션을
   열지 않는다**(다음 이벤트를 막지 않는다).
7. **저유동성 판정 시점**: 장대양봉 봉까지 정제한 df(진입 시각에 알 수 있는 데이터) — 이전 측정의 "진입봉까지"와 같은 뜻.
8. **반분**: A 진입일 중앙값 하나로 A·C를 함께 나눈다(이전 측정과 같음).
9. **"돌파 전 600일선 아래 기간"(기록)**: 장대양봉 전일부터 거슬러 종가 < MA600이 이어진 유효봉 수. MA600을 계산할 수 있는 첫 봉에
   닿으면 하한으로 표시(`capped`).
10. **데이터 범위**: 앞 세 측정과 같은 캐시(KIND, naver 1,900일)를 쓴다. 600봉 워밍업 때문에 이벤트는 대략 **2023-12 이후 약 2.8년**에서만
    나온다. 대안: 더 긴 이력(예: 3,000일)을 새로 받아 기간을 늘린다(유니버스는 그대로, 신규 fetch).
