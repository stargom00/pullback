## §1. 사전등록 (사용자 지시·확인, 2026-11-10)

**사용자 원문**:
- (시스템 기대값 측정 제안에) "해."
- "전체비율중 5%에 닿지않는게 7%정도라면 그리크진않은데, 이런 저점 종목이 결국 상승하기 때문에 5%가 고민되는거야. 이미 많이 오른건
  조정이 올거고, 상장하고 아직 큰 상승이 나오지않은건 올라갈 확률이 높다고 보기때문."
- 기본값 확인: "100%이상." (큰 상승 기준) · "상장가로." (기준 가격) · "좋아" (보유 한도 250거래일)

### H1 — 시스템 전체 (측정만, 판정 없음)
모든 매매(+5% 미도달 포함)를 사용자 규칙대로 끝까지 따라간다.

| 규칙 | 값 | 출처 |
|---|---|---|
| 익절 | 고가 ≥ 매수가×1.05 → 보유 전량을 max(그날 시가, 매수가×1.05)에 매도, 매매 종료 | 사용자 규칙 · 11-10 측정 |
| 물타기 | 저가 ≤ 매수가×0.5 → 1차와 같은 수량을 min(그날 시가, 매수가×0.5)에 추가 | 사용자("-50%이상 내려가면 같은양으로 진입") |
| 덜어내기 | 추가분 보유 중 고가 ≥ 평단((매수가+추가가)/2) → 추가분만 max(그날 시가, 평단)에 매도. 이후 다시 −50%면 다시 추가(반복 허용) | 사용자("본전에오면 추가분을 다시 덜어내", 본전 = 물타기 후 평단) |
| 원래 물량 목표 | 계속 매수가×1.05 | AI 기본값(사용자 확인) |
| 한 봉 안 순서 | 익절 → 덜어내기 → 물타기 순으로 본다(물타기한 봉에서는 덜어내기 안 함) | AI 기본값 |
| 보유 한도 | 매수일부터 250거래일 — 끝나면 남은 물량을 그날 종가로 평가, "미청산"으로 따로 집계 | 사용자 확인("좋아") |
| 비용 | 매도 금액의 0.25%(세금+수수료 어림) | AI 어림값(근거 없음) |
| 기록 | 건당 수익(1차 매수금 대비 %, 그리고 실제 투입금 대비 %) 평균·중앙값·하위 5%, 익절·미청산 비율, 물타기 발생률, 최대 투입금(1차 대비 배수), 돈이 묶인 일수(투입금×일 ÷ 1차 매수금), 연환산 참고값(평균 수익 ÷ 평균 묶인 일수 × 250) | AI 기본값(사용자 확인) |

### H2 — "상장 후 아직 큰 상승 없음" 그룹에서 +5% 이후 보유
| 항목 | 값 | 출처 |
|---|---|---|
| 그룹 | ① 조회 창(1900일) 안에서 상장(데이터 시작이 창 시작 +30일 이후) **그리고** ② 상장 이후 신호 기준일까지 최고 종가 < **상장가 × 2.0** | 사용자("100%이상", "상장가로") |
| 상장가 | **상장 첫 거래일 시가** — 공모가 데이터가 없어 첫날 시가로 대신한다(데이터 한계) | 사용자("상장가로") + AI 해석 |
| 비교 | 그룹 안 +5% 도달 건에서 11-10 측정의 R1~R4 vs R0(전량 +5%), 짝 차이 Rk − R0 | 11-10 측정 정의 그대로 |
| 판정 | 규칙별 z ≥ 2.50(Bonferroni 4) · +5% 도달일 중앙값 반분 양쪽 평균 차이 > 0 · n ≥ 100 | 11-10과 같음 |
| 대조(기록만) | 그룹 밖 +5% 도달 건의 같은 수치 | AI 기본값 |

**출처 고지**: 2.0배(+100%)·상장가는 사용자 지정. 0.25%·한 봉 안 순서·대조군은 근거 없는 AI 기본값. 11-10 측정 결과(전체에서 R1~R4 기각)를
이미 본 뒤의 세분 가설이다 — 같은 데이터에서 그룹을 골라 다시 재는 것이므로, 통과해도 "그룹 차이 후보"로만 기록하고 확인군(이후 데이터)
사전등록 전에는 채택하지 않는다(등록부 "탐색" 원칙과 같은 취지).

## §1-구현
1. 신호·워밍업·중복·저유동성·250거래일 경로·R0~R4 계산은 11-10 스크립트의 함수를 import해 쓴다(`weekly_hits`·`self_check_hits`·`simulate`·`zstat`).
2. 상장 판정과 상장가는 원본 일봉(정제 전) 첫 봉. 최고 종가는 기준일까지 정제한 종가(`CleanView.prefix`)로 본다.
3. H1 경로는 11-10과 같은 `CleanView.future` 250봉. 물타기·덜어내기 체결가는 위 표의 지정가 규칙.
