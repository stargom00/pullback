# 전 탭 공통 잣대 측정 (2026-08-08)

`docs/abc_doc_style_tab_investigation.md`에서 쓴 시점매칭 대조군 방식을 전 탭으로 확장해, "탭을 정리하기 전에 전 탭 성과를 같은 잣대로 재자"는 요청에 따라 진행한 측정 기록. 급등매집→탭전이 조사에서 "매집 흔적 → 곧 터진다"는 전제가 무너졌던 경험이 이번에도 반복됐다.

## 방법론

- **2R 레이스**: 진입=신호일 종가(또는 모드별 진입가), 손절=모드 자체 `stop` 필드, 목표=진입+2×(진입-손절), 최대 60봉까지 레이스. 결과 ∈ {손절, 도달, 미결, 데이터부족}. `EV_R = (도달/nv)×2 + (손절/nv)×(-1)`, `nv`는 데이터부족만 제외.
- **시점매칭 대조군**: 같은 시장, 같은 상대 체크포인트(`off`=시리즈 끝에서 거래일 수), 무작위 종목을 뽑아 동일 레이스를 돌려 비교.
- **체크포인트**: `off=60..250` (10 간격, 20개 지점) 전체 유니버스에 대해 반복 — 스냅샷 하루가 아니라 다수 시점 평균.
- **일평균 히트 수**: `n_hits / 체크포인트 수(20)`로 근사 — EV가 높아도 하루 1건이면 못 쓰고, EV가 낮아도 하루 50건이면 그 안에서 다시 고를 수 있다는 이유로 항상 병기.

## 대상 탭 및 분리 이유

`stop`/`risk_pct` 필드가 있는 7개 탭(눌림목/추세전환/돌파/박스돌파/돌파임박/패턴4종)은 **Script A**로 2R 레이스 측정. `analyze_leader`(대장후보)/`analyze_super`(슈퍼대장)/`analyze_stage2`는 stop 필드 자체가 없어 억지로 2R을 씌우면 숫자는 나와도 의미가 없다는 판단(사용자 확인: "좋은 판단이야... B로 나눠서 재는 게 맞아") 하에 **Script B**로 별도 측정(최대상승/하락 분포 + N봉내 ±15% 터치율). IBD9/실적우수/강한피벗은 이번 라운드 제외(백테스트 설계 자체가 다름).

## Script C — 오늘 스냅샷 중복도

같은 날 각 탭 히트 수와 pairwise 중복 매트릭스. 돌파임박↔눌림목 중복 39건(돌파임박 116건의 34%), 대장후보↔슈퍼대장 중복 31건(51%) — 이후 대장후보→눌림목 연결 설계 논의의 근거로 사용.

## Script D — 슈퍼대장 status별 분해

status 7종(신고가/눌림 진행/조정 깊음/20일선 테스트/20일선 지지✓/50일선 테스트/50일선 지지) 전부 +15%터치율 87~94%, near_buy_zone True/False도 89.3% vs 89.1%로 거의 무차이 — **슈퍼대장의 우위는 진입 타이밍/자리가 아니라 "RS95+ 리스트 소속" 자체에서 나온다**는 결론. 대장후보→눌림목 전이율 74.0%(중앙값 6봉)로, 급등매집→any탭 26.4%(별도 측정, `surge_accum_followup.py`)와 대비되는 강한 신호.

Script D는 슈퍼대장 손절 설계 3안(안1 단순손절/안2 구조손절/안3 신고가돌파)의 "buy_zone 즉시체결" 가정 하 EV도 함께 냈으나(안1 EV_R=1.22), 이 가정 자체가 검증되지 않아 Script F로 별도 재확인 진행(아래).

## Script E — Stage2 유동성 필터 적용 재측정

app.py `_run_scan_stage2`의 실제 파이프라인(20일 평균거래대금 ≥20억원 KR전용 컷 + `rs_score_stage2`로 생존자 안에서 재백분위)을 그대로 재현.

| 지표 | 유동성필터 전(Script B) | 유동성필터 후(Script E) |
|---|---|---|
| 일평균 히트 | 74.9 | 16.7 (1/4.5로 급감) |
| 실제 +15%터치율 | 64.2% | 75.1% |
| 대조군 +15%터치율 | 60.8% | 72.8% |
| 실제 -15%하락률 | 43.7% | 55.1% |
| 대조군 -15%하락률 | 48.3% | 50.9% |

유동성 필터를 걸면 표본이 1/4.5로 줄고, 상승 우위는 +2.3pp로 더 약해지는 반면 **하락 위험은 대조군보다 4.2pp 더 나쁨** — 유동성 필터가 우위를 강화하는 게 아니라 모수만 깎고 하방을 악화시킴. Stage2는 패턴 4종과 같은 "검증실패" 취급으로 판정.

## Script F — 슈퍼대장 안1 buy_zone 터치율 검증 (생존편향 재확인)

D의 안1 EV(1.22)는 "신호 즉시 buy_zone 진입"을 가정한 수치였고, 어제 안C에서 겪은 것과 같은 함정(터치 못 한 신호가 통계에서 빠짐)이 아닌지 확인 필요 — 사용자 명시적 게이트: "이거 통과하면 카드에 붙이고, 아니면 재설계."

- N봉 내 buy_zone 터치율: 5봉 49.9% / 10봉 56.1% / 20봉 63.6% / **60봉 72.1%** (즉, 60봉 내내 못 만나는 신호가 27.9%)
- 60봉 내 미터치 종목의 운명: 최대상승 중앙값 **+75.4%**, +15% 터치율 **99.2%** — buy_zone까지 기다리다가 못 만나는 종목일수록 오히려 이미 크게 갔던 종목이었다는 뜻(대기=최고 수익 기회를 놓치는 구조).
- 터치한 것만의 실제 EV: **0.361** (D의 1.22와 크게 다름 — 즉시체결 가정이 EV를 3배 이상 과대평가했음)
- 하이브리드 EV(미터치=진입없음=0R 포함 전체): **0.26**

**결론: 안1은 게이트를 통과하지 못함.** buy_zone 대기 진입 설계는 안C와 동일한 생존편향 함정이었다. 카드에 붙이지 않음 — 재설계 필요(다음 라운드 논의 대상).

## 반영된 조치

- `#modeTabs`에서 패턴 4종/Stage2 탭을 `tab-exp` 클러스터 끝(섹터 앞)으로 재배치, `검증실패` 배지(`.exp-tag.danger`) 부착.

- 슈퍼대장 안1(진입 좌표 부착)은 보류, 재설계 필요.
