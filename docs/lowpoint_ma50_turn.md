# 저점에서 50일선 첫 돌파 — 상승 전환 성공률과 공통 특징 (탐색)

> 2026-11-14 등록. 계기(사용자 원문): "저점매매할때, 너무 기다리는 시간이 길어. 상승추세가 시작될때 진입하고싶은데,
> 50선위로 올라갈때 어떤지 조사해봐. 불특정 다수의 종목을 골라서 저점에서 바닥 다지고 상승추세로 전환할때,
> 공통적으로 보이는 현상이뭔지 조사해줘"
> 분류: **H1 측정만 · H2 탐색(판정 없음)** — 여기서 나온 특징은 확인군 사전등록 전에는 채택하지 않는다.

## §1. 사전등록 (실행 전 고정 — 결과를 본 뒤 바꾸지 않는다)

### 1.1 데이터
- KR 전 종목: naver 모바일 marketValue 목록(KOSPI+KOSDAQ, `naver_kr._is_etf_like` 제외) — 실행일 기준 상장 종목.
  KIND 목록(운영 저점 스크린의 유니버스)은 이 환경에서 접근이 막혀 대체했다 → **관리종목이 섞이고 상장폐지 종목은 없다(생존 편향)**.
- 일봉: naver 통합 시세 `fetch_history(days=3000)`, `harness.CleanView`로 정제(무거래일 OHLC=0 봉 제거, 체크포인트 접두 정제).
- 실행 창: `harness.check_run_window(("kr",))`, 결과 JSON에 `harness.run_stamp()`.

### 1.2 사건 E — "저점에서 바닥 다진 뒤 50일선 첫 돌파" (돌파 당일 j까지의 정보만)
1. 돌파: 종가[j] > SMA50[j] 그리고 종가[j−1] ≤ SMA50[j−1] (SMA = 단순평균, 종가 기준)
2. 저점: 최근 120봉(j 포함) 최저 저가 ≤ 최근 250봉 최고 고가 × 0.60 — 사용자 선택 "1년 고점 −40%↓"
3. 바닥 다지기: j 직전 60봉 중 종가 < SMA50인 봉 ≥ 40 — 사용자 선택 "60일 중 40일↑ 50선 아래"
4. 이력 ≥ 250봉(SMA200·1년 고점용), 20일 평균 거래대금 ≥ 5억원(AI 어림값 — 거래가 거의 없는 종목 제외, 측정 근거 없음)
5. 같은 종목은 사건 뒤 60봉 동안 새 사건을 세지 않는다(AI 어림값)

### 1.3 진입·결과 — 사용자 선택 "+30% 먼저 vs −15% 먼저"
- 진입 = j 다음 거래일 시가. 그날부터 최대 120거래일.
- **성공**: 고가 ≥ 진입가×1.30이 먼저. **실패**: 종가 ≤ 진입가×0.85가 먼저. 같은 날 둘 다면 실패(보수적).
- **미결**: 120일 안에 둘 다 없음 — 120일째 종가 수익률만 기록, 성공·실패 비교에서 뺀다.
- 기록만: 20·60·120일 종가 수익률, 120일 안 최대 상승·최대 하락.

### 1.4 H1 측정만 — 50일선 돌파가 무엇을 더하나
- 대조군 C: 같은 날짜 조건 2·3·4를 만족하지만 **종가 ≤ SMA50**(아직 돌파 전)인 날, 종목당 60봉 간격으로 고른 날(결정적 — 조건을 만족하는 첫 날, 그 뒤 60봉 건너뜀). 진입·결과 판정은 E와 같다.
- 기다림 비용: 120봉 최저 저가 날 → 돌파일 거래일 수, 최저 저가 → 돌파일 종가 상승률(바닥에서 이미 오른 몫).
- 기록: E·C 성공률·실패률·미결률, 차이의 두 비율 z. **판정 없음**(측정만).

### 1.5 H2 탐색 — 성공 vs 실패에서 다른 특징 (돌파일 j까지의 정보)
| 키 | 특징 |
|---|---|
| F1 | 돌파일 거래량 ÷ 직전 50일 평균 거래량 |
| F2 | 돌파일 몸통 = 종가÷시가 − 1 |
| F3 | 돌파일 종가 위치 = (종가−저가)÷(고가−저가) |
| F4 | 갭 = 시가÷전일 종가 − 1 |
| F5 | SMA50 기울기 = SMA50[j] ÷ SMA50[j−10] − 1 |
| F6 | 종가 ÷ SMA200 − 1 |
| F7 | 바닥(120봉 최저 저가)부터 경과 거래일 |
| F8 | 바닥 대비 돌파일 종가 상승률 |
| F9 | 하락 깊이 = 바닥 ÷ 250봉 최고 고가 − 1 |
| F10 | 직전 120봉의 50일선 돌파 실패 횟수(돌파 뒤 5봉 안에 종가가 다시 SMA50 아래) |
| F11 | 저점 높이기 = 최근 20봉 최저 저가 ÷ 바닥 − 1 |
| F12 | 변동성 수축 = ATR20[j] ÷ ATR20[j−60] |
| F13 | 바닥권 거래량 = 최근 20봉 평균 거래량 ÷ 바닥 이전 60봉 평균 거래량 |
| F14 | 일봉 RSI14(고전 Wilder, `lowpoint.rsi_wilder_sma`) |
| F15 | SMA20 > SMA50 (불리언, 0/1) |

- 비교: 성공 vs 실패 Mann-Whitney z(`harness.mannwhitney_zscore`), 표준화 평균차, 사분위별 성공률.
- **"차이 있음" 표기 = |z| ≥ 2.94(양측 0.05 Bonferroni 15) 그리고 시기 반분(사건 날짜 중앙값) 양쪽 같은 부호.** 이건 서술용 표시이고 채택이 아니다.
- 표본 하한: 성공·실패 각 n ≥ 100 미만이면 하드 실패(결과 표에 0으로 남기지 않는다).

### 1.6 한계 (결과 해석 시 고정)
- 생존 편향(현재 상장 종목만) — 실패가 과소 추정될 수 있다.
- 약 8년(3,000일) 한 번의 표본, 수수료·슬리피지 없음.
- 숫자 0.60·40/60·5억·60봉 간격은 사용자 선택 또는 AI 어림값이다(위 각 줄에 표기).
