# KR/US 시장별 전략 지도 (2026-08-29)

> 이 문서는 **측정 결과 기록**이다. 판정(어느 탭을 KR/US로 분리 운영할지,
> UI/scanner.py를 바꿀지)은 사용자 결정 대기 — 이번 라운드에서는 수치만
> 정리한다(사용자 지시: "결과 나오면 판정은 보고 후에").

## 배경

`docs/pullback_ev_kr_us_regime_investigation.md`에서 눌림목·슈퍼대장의
KR/US 분해가 이미 나와 있었다(둘 다 US가 견인, KR이 부진하고 z 유의).
이 문서는 나머지 주요 탭/필터(돌파임박·돌파·박스돌파·추세전환·E 게이트
증분·depth_atr 증분)까지 같은 방식으로 분해해 "US에서 작동하는 것 / KR에서
작동하는 것 / 어디서도 유의하지 않은 것" 전체 그림을 채운다.

## 방법론

- **체크포인트**: `harness.checkpoints(60, 250, 10)` — 20개 지점, 이 레포의
  표준 스펙(규칙6/7/8 근거 문서들과 동일).
- **히트 판정**: 각 탭의 실제 프로덕션 `analyze_*()` 함수 + 현재
  CONFIG(v5.71 기준 — 눌림목은 게이트E/depth_atr 반영 최신판, 돌파·박스돌파는
  v5.70의 rs_min 탭별 분리 반영, 추세전환·돌파임박은 원 CONFIG) 그대로 호출.
  `harness.passes_liquidity_filter()` 저유동성 하드컷 포함.
- **KR/US 분해**: `harness.is_kr_ticker()`로 히트를 시장별로 나눠 각각
  `harness.ev_summary()`.
- **유의성**: `harness.ev_gap_zscore()` (규칙7) — 양측 95% 기준(|z|≥1.96).
- **규칙6(대조군 유동성매칭)은 해당 없음** — 대조군과 비교하는 측정이 아니라
  실제 히트 코호트를 시장별로만 쪼개는 측정이라 대조군 자체가 없음.

근거 스크립트: `scripts/measurements/2026-08-29_kr_us_decomposition_final.py`
(전체 유니버스 재fetch, 실행 시점 데이터 기준 — 재현하면 그 시점 수치가 나옴).

## 관찰 (판정 아님 — 사실 나열만)

- **US가 유의하게 높은 쪽**: 눌림목, 슈퍼대장, 돌파임박 — 3개 다 z≥1.96.
- **KR이 방향상 높지만 유의하지 않은 쪽**: 돌파, 박스돌파, 추세전환 — 3개
  다 |z|<1.96 (1.4~1.6대), 방향은 KR 우세지만 "우연과 구분 안 됨" 기준을
  못 넘음.
- **E 게이트 증분(측정 1)**: US가 방향상 높지만(US 0.135R vs KR 0.025R)
  z=0.99로 유의하지 않음 — "🔥단기주도/🚀랭크급등 경로가 US 전용 엣지"라는
  가설도, "KR에서도 작동하는 유일한 경로"라는 반대 가설도 이번 표본(KR
  n=240, US n=540)으로는 통계적으로 뒷받침되지 않는다. 방향 자체는 US가
  높지만 우연과 구분 안 됨.
- **depth_atr 증분**: KR은 표본 92건에 EV가 사실상 0 근처(-0.022R), US는
  310건에 0.210R로 방향 격차가 가장 크지만(+0.231R) z=1.37로 역시 유의성
  기준 미달 — 표본이 작아(특히 KR 92건) 아직 판단하기엔 이르다.
- 전체적으로 "돌파류(돌파/박스돌파) + 추세전환"과 "눌림목류(눌림목/슈퍼대장/
  돌파임박)"가 KR/US 우위 방향에서 갈리는 패턴처럼 보이나, 전자 3개는
  전부 유의성 기준을 못 넘겨 이게 실재하는 구조적 차이인지 표집 잡음인지는
  이번 측정만으로 확정할 수 없다.

## 사전 등록 합산 검정 (2026-08-29)

위 "관찰" 절의 패턴(돌파류+추세전환 vs 눌림목류)이 개별 탭 단위로는 전부
|z|<1.96(우연과 구분 안 됨)이었던 문제를 풀기 위해, 두 계열을 **탭별이
아니라 계열 단위로 합산**해 표본을 키운 검정을 사전 등록 후 실행했다.

**측정 전 고정 가설**: "KR에서는 돌파 계열(돌파+박스돌파+추세전환 합산)이
되돌림 계열(눌림목+돌파임박 합산)보다 EV가 높다." US는 대칭 확인 목적으로
반대 방향(되돌림 계열 우위)을 기대.

**측정 전 고정 판정 기준**: KR 격차(돌파계열EV − 되돌림계열EV) ≥ +0.1R
**그리고** z ≥ 1.96이면 "KR = 돌파 계열 우위" 채택 → GUIDE에 시장별 권장
탭 기록. 미달이면 방향성 관찰로만 기록하고 표본 축적 대기.

각 계열은 탭 배타성을 가정하지 않고(한 종목이 같은 체크포인트에서 여러
탭에 동시 히트해도 각 탭 히트는 서로 다른 entry/stop/목표를 가진 별개
트레이드라 전부 포함) pooled outcomes로 합산. 규칙8(KR/US 미혼합)을
지키기 위해 KR 내부·US 내부 각각에서만 두 계열을 비교했다.

### 판정

**KR: 기준 충족 → "KR = 돌파 계열(돌파/박스돌파/추세전환) 우위" 채택.**
격차 +0.283R, z=4.88 — 사전 등록 기준(+0.1R 이상 & z≥1.96)을 여유 있게
충족. 개별 탭 단위로는 안 보이던 신호가 계열 합산(표본 860 vs 2,554)으로
표본이 커지면서 통계적으로 드러났다.

**US: 대칭 확인 — 방향은 일치하나 유의하지 않음.** 격차 -0.008R, z=-0.16으로
부호는 가설대로 반대(되돌림 계열 쪽으로 미세하게 기움)이지만 사실상 0에
가까워 "US는 되돌림 계열 우위"라고 채택할 근거는 없다. 즉 US 쪽 이야기는
**대칭 확인 실패**(부호만 맞고 크기가 없음) — KR의 뚜렷한 돌파 계열 우위와
달리 US는 두 계열이 사실상 무차이다. 개별 탭 결과(눌림목/돌파임박이 US에서
유의하게 높았던 것)와 종합하면, US의 특징은 "돌파 계열이 열세"가 아니라
"되돌림 계열(특히 눌림목·돌파임박)이 KR보다 훨씬 잘 작동해서 두 계열이
비슷한 수준까지 따라잡힌 것"으로 해석하는 게 더 정확하다.

## KR 눌림목 EV 재조사 — 0.002R(n=636) vs 0.175R(n=559) 정합 (2026-08-31, 사용자 지시)

### 배경

### 확인 1 — 체크포인트 방법론은 동일, 실행일만 5거래일 밀림

두 계보(`2026-08-26_pullback_ev_cohort_and_pipeline_diff.py`,
`2026-08-31_kr_pullback_liquidity_tercile_ev.py`, 오늘 신규
`2026-08-31_kr_pullback_ev_reconciliation.py`) 전부 `checkpoints(60,250,10)`

역산이라, 2026-08-26 실행분과 2026-08-31 실행분은 커버하는 실제 캘린더

### 확인 2 — CONFIG/파이프라인 차이 발견: price_frozen 배제가 중간에 추가됨

`price_frozen`(M&A 의심 가격고정) 배제를 추가했다:

즉 0.002R/n=636 측정(2026-08-26, v5.90 이전)은 이 배제가 없었고, 오늘

실제로 파이프라인이 바뀐 지점이 하나 있다. 다만 가격고정 종목 자체가
전체 유니버스에서 드물어(v5.90 문서 참고) 이 차이가 0.17R급 EV 이동을

### 판정 — 국면 의존성이 진짜다, "무용 확정"은 과도한 단정이었다
