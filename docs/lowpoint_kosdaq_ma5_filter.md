## §1. 사전등록 (실행 전 고정)

### 1.1 매매 표본 — 기존 시스템 기대값 측정을 그대로 재사용(사본 없음)
- `scripts/measurements/2026-11-10_lowpoint_system_expectancy_listing.py`의 매매 목록(`trades`)을 그대로 쓴다:
  주봉 저점 신호(운영 정의) → 다음 날 시가 매수(시가 ≥ 기준가×1.05면 제외) → 사용자 규칙 전체(+5% 전량 익절,
  −50% 같은 수량 추가, 평단에서 추가분 덜어내기, 비용 0.25%, 최대 250거래일) = `system.ret`(1차 매수금 대비 %).
- 데이터: naver 통합 일봉 1,900일. **유니버스는 naver 시총 목록**(KIND 목록은 이 환경에서 접근 차단) — 관리종목이 섞이고
  상장폐지 종목이 없다(생존 편향). 11-10 측정과 유니버스가 달라 절대값은 직접 비교하지 않는다.

### 1.2 필터
- **위** = 매수일 직전 거래일(KR) 코스닥 지수 종가 > 그날까지 5일 단순평균. **아래** = 그 외(같음 포함).
- 지수: `naver_kr.fetch_index_history("KOSDAQ")`. 매수 시점에 이미 확정된 값만 쓴다(룩어헤드 없음).
- 모든 매매(KOSPI·KOSDAQ 종목)에 같은 코스닥 필터를 쓴다(채널이 쓰는 방식). KOSDAQ 종목만은 기록용.

### 1.3 판정 (Bonferroni 2 → z ≥ 2.24)
- O1 `system.ret` 평균: 위 − 아래 Welch z.
- O2 묶임률(`system.exit == "cap"`, 250일 안 +5% 못 감): 아래 − 위 두 비율 z(양수 = 위가 덜 묶임).
- **필터 채택** = O1 z ≥ 2.24 그리고 시기 반분(매수일 중앙값) 양쪽 평균 차 > 0 그리고 위·아래 각 n ≥ 100.
  O2는 같은 문턱으로 따로 표시. 반대 방향(아래가 더 좋음)도 같은 문턱이면 "역방향"으로 기록한다.
- 표본 0·한쪽 n<100이면 하드 실패.
