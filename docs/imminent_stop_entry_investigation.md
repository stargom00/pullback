# 돌파임박 손절/진입 정의 + tightening·vol_dry 가점 조사 (2026-08-08)

**결론(반영됨, v5.40~v5.43)**:
1. `_risk_hard_ok`를 loosen-only ATR 완화(v5.40)로 변경, breakout/boxbreak는
   게이트를 카드 표시(현재가) 기준으로 통일 + boxbreak에 extended_max 신설
   (v5.41).
2. 손절폭 절대값 4단계 배지 추가(v5.42).
3. **눌림목/돌파임박 score에서 tightening 가점 완전 제거, vol_dry 20점 절벽을
   연속식으로 전환(v5.43)** — 아래 3장 실측 근거.

모든 수치는 **백테스트가 아니라 규칙 비교용 근사치**다. 슬리피지·거래비용·
분할매매 없음, 진입가는 라운드마다 명시한 기준(종가/고가/피벗)을 그대로
사용. 실제 수익률 추정치로 쓰면 안 된다. RS는 "현재 시점 전체 히스토리로
계산한 고정값"을 과거 체크포인트에 재사용(선견편향 있음 — 이 세션의
entry_signal_4item.py 등 기존 측정 스크립트와 같은 컨벤션).

## 1. 발단 — 게이트 vs 카드 표시 risk_pct 불일치 (v5.39 debug 패널 이후)

debug 패널 수정(v5.39) 과정에서 `_risk_hard_ok`의 실제 판정 기준(피벗
기준)과 카드에 표시되는 risk_pct(entry=close 기준)가 다를 수 있다는 게
드러남 — DELL 사례: 카드 6.55%, 게이트 9.02%. 전체 유니버스로 괴리 분포를
재보니:

- pullback: 중앙값 3.41%p, DELL의 2.47%p는 37번째 백분위(평범).
- breakout/boxbreak: **전부(100%)** 게이트값이 카드보다 작은 방향으로 치우침
  — `stop=pivot×0.97`로 손절이 피벗에 고정돼 연장(ext)이 커질수록 괴리가
  커지는 구조. boxbreak 최악 사례(051160.KQ): 피벗 대비 이미 +35.5% 연장,
  카드는 29.0%로 정확히 보여주는데 게이트는 3.79%로 계산해 통과시킴.

**조치**: breakout/boxbreak는 `_risk_hard_ok` 호출에서 `pivot` 인자 제거해
카드(현재가) 기준으로 통일 + boxbreak에 `extended_max=0.12` 신설(breakout과
동일). pullback은 `_risk_hard_ok` docstring에 문서화된 이유(Case13: 돌파일
종가 기준으로 판정하면 정상 셋업이 잘림)로 그대로 둠.

검증(동일 캐시 데이터, patch 전/후 실제 프로덕션 함수 diff): pullback 변화
0건, breakout 17→11(-6), boxbreak 24→9(-15, 051160.KQ 포함 고연장 종목 전부
제외 확인), imminent 대상 아님(126건 그대로).

## 2. `_risk_hard_ok` ATR 완화 (v5.40)

badge_fields의 `stop_wide`가 이미 ATR×1.5를 쓰는데 `_risk_hard_ok`는 고정
US8%/KR12%로 남아있던 불일치. loosen-only(`max(고정, min(ATR%×1.5, 15%캡))`)
채택 — 전체 유니버스 측정에서 순수 ATR×N 치환은 저ATR 종목을 새로 탈락시켜
역효과(전체 히트 감소)가 났고, loosen-only만 순수 증가였음. 15% 절대상한은
ATR 커도 무제한 완화를 막기 위함.

## 3. 손절 정의 A/B/C/D 비교

### 3.1 정의

- **안A(현행)**: 진입=신호일 종가, 손절=`analyze_imminent`가 실제 계산하는
  구조적 지지(significant_support/MA20×0.98)+ATR버퍼(0.15).
- **안B(앤트킹식, 손절만)**: 진입=신호일 종가(안A와 동일), 손절=신호일 저가.
- **안C(앤트킹식, 진입+손절 세트)**: 진입=신호일 다음날부터 N=3봉 이내에
  신호일 고가를 장중 고가로 돌파 **+** 그날 거래량이 트레일링 50일 평균의
  1.5배 이상 → 그 돌파일에 진입(진입가=신호일 고가 레벨). N봉 안에 못 뚫으면
  미진입(레이스 자체를 안 함). 손절=신호일 저가.
- **안D(시점매칭 대조군)**: 안C가 실제 진입한 그 날짜에, 조건 없이 종가로
  진입. 손절은 비교 목적에 따라 두 버전(D=구조적 손절 안A와 동일 / D′=안C와
  동일한 신호일 저가).

레이스: 진입 시점부터 최대 60봉, 그날 저가≤손절이면 손절, 고가≥목표면 도달,
같은 날 둘 다 걸리면 보수적으로 손절 우선. 60봉 안에 둘 다 안 걸리면 미결.

### 3.2 15% 고정 목표 기준 결과 (n=3622 신호, KR+US 전체)

| | 진입률 | 손절폭(median) | 손절률 | 도달률(15%) |
|---|---|---|---|---|
| A | 100% | 4.31% | 67.9% | 30.9% |
| B | 100% | 1.50% | 85.1% | 14.7% |
| C(진입분만, n=701) | 19.4% | 3.42% | 56.2% | 43.1% |
| D(시점매칭, 손절=구조적) | 18.9%(=C와 동일 시점) | 9.21% | 44.8% | 51.1% |

안B는 손절이 얕아지지만(median 1.5%) 그만큼 정상 노이즈에 잘 털려 손절률이
85.1%로 치솟음 — "타이트함"이 구조적 근거(지지선 확인)가 아니라 "그날
우연히 좁았던 범위"라 다음날 노이즈에 취약. 신호일 봉 범위(고가-저가)/종가
분포: median 3.37%, ≤5%가 76.8% — 대부분 좁은 날이라 안B가 median 1.5%라는
타이트한 손절폭을 거의 항상 만들어내지만, 그 좁음이 유효하지 않다는 뜻.

### 3.3 필터 vs 시점 지연 분해 (D vs D′, C1/C2 분해)

D(구조적 손절)는 손절폭이 median 9.21%로 A(4.31%)보다 넓어 도달률이 자동
상승하는 착시가 섞임 — 손절을 C와 동일(신호일 저가)로 맞춘 **D′**로
재비교:

| | 손절률 | 도달률(15%) |
|---|---|---|
| D′(시점매칭, 손절=C와 동일) | 59.5% | 38.8% |
| C(필터+손절 세트) | 56.2% | 43.1% |

D′→C 순수 필터 효과 +4.3%p — 방향은 일관되게 긍정적이지만 크기는 작음.

조건 분해(고가돌파 단독 vs 거래량 단독 vs 결합, 손절은 전부 신호일 저가로
통일):

| | 진입률 | 손절률 | 도달률(15%) |
|---|---|---|
| C1(고가돌파만) | 71.6% | 74.9% | **24.7%(안A 30.9%보다도 나쁨)** |
| C2(거래량만) | 19.7% | 63.0% | 35.4% |
| C(둘 다) | 19.4% | 56.2% | 43.1% |

**"고가를 넘었다"는 조건 자체엔 거의 정보가 없음**(C1이 거의 다 통과하고
성적도 나쁨) — 실제 신호는 거래량 쪽. 결합 시 거래량 단독보다도 더
개선되는 걸 보면 두 조건이 시너지는 있음.

### 3.4 신호일 봉 범위와 결과 — "타이트하면 좋다" 가설은 반대로 확인됨

C1(고가돌파만) 기준 범위 버킷별 성적:

| 범위(고가-저가/종가) | 손절률 | 도달률 |
|---|---|---|
| ≤2% | 63.5% | 33.9% |
| 2~3% | 67.9% | 31.5% |
| 3~5% | 50.4% | 49.6% |
| 5%+ | **48.4%** | **51.0%** |

**정확히 반대 방향** — 좁을수록 나쁘고 넓을수록 좋음. 등락률(그날 상승폭)
교란 우려 확인: 5%+ 구간의 change_pct median은 **-0.44%**(큰 양봉 때문이
아님). 등락률을 -3%~+3%(평범한 날)로 통제한 뒤 재분석해도 방향 그대로,
오히려 격차가 더 커짐(≤2%: 손절83.4%/도달15.6% vs 5%+: 손절64.6%/도달35.4%)
— 진짜 range effect, 등락률 교란 아님. **"봉 범위 압축" 지표를 새로 만드는
아이디어는 이 데이터로는 근거 없음(오히려 반대).**

### 3.5 R 기준 재계산 — "시점 지연 착시" 가설은 기각됨

목표를 15% 고정 대신 손절폭×2(2R)로 잡고(손절 넓어지면 목표도 같이
넓어지게 통제) 재계산:

| | 손절률 | 도달률(2R) | EV(R, 미결=0R) |
|---|---|---|---|
| A | 59.6% | 39.7% | 0.199R |
| D(시점만 이동, 무필터, 손절=구조적) | 43.8% | 47.9% | 0.520R |
| **C(필터+손절 세트)** | 39.9% | 59.8% | **0.796R** |

R로 정규화해도(같은 $ 리스크로 포지션 사이즈를 조정한다고 가정해도) C가
A의 4배, D보다도 우세 — "손절 넓혀서 도달률 올라간 착시"는 15%-고정-목표
비교에서는 실제로 있었지만(A→D의 도달률 급등 상당 부분), R 단위로 공정하게
비교해도 C의 우위는 사라지지 않고 오히려 더 뚜렷해짐.

### 3.6 생존편향 확인 — **여기서 이번 조사의 핵심 결론이 나옴**

C의 진입률은 19.4%(701/3622) — 나머지 80.6%(2921건)는 60봉 내내 신호일
고가를 거래량 동반해서 못 뚫음(미진입). 미진입 건이 신호 후 어떻게
됐는지:

- 60봉 내 최대 상승률: median +29.91%, p75 +54.2%. **+15% 이상 터치 74.6%**,
  +20% 이상 65.4%.
- 60봉 내 최대 하락률: median -9.0%, p25 -15.72%. -10% 이상 하락 터치 44.9%,
  -20% 이상 15.0%.

양방향으로 변동성이 큰 그룹 — "미진입=죽은 종목"이라는 단순한 그림은
아님. 그런데 **EV 재계산이 결정적**이었다: 미진입 건을 "안A 방식으로
진입했다면"으로 가정한 하이브리드(안C보완: C가 진입하면 C대로, 안 하면
A대로, 목표는 전부 2R)로 전체 3622건 커버리지를 다시 계산:

| | EV(R) | n | 커버리지 |
|---|---|---|---|
| 안A 전체(기준) | 0.1988R | 3622 | 100% |
| **안C 진입분만** | **0.796R** | 701 | 19.4% |
| **안C보완(미진입=안A로 대체)** | **0.1632R** | 3622 | 100% |

**하이브리드가 순수 안A보다도 낮다.** 역산하면 미진입 서브셋에 안A를
적용했을 때 EV는 약 0.011R — 사실상 0. 즉 **안A 전체의 EV(0.1988R)는
거의 전부 "나중에 C 조건을 확인하게 될 그 701건"에서 나오고 있었고**,
나머지 80.6%는 안A로 진입해도 의미가 없는 그룹이었다.

**해석**: 안C의 가치는 "손절폭을 신호일 저가로 정의한 것"이나 "진입가를
신호일 고가로 정의한 것" 같은 **가격 공식에 있지 않다.** 진짜 가치는
**"거래량 동반 확인 전에는 아예 진입하지 않는다"는 규율** 그 자체에 있다
— 확인 안 되는 80.6%에 자본을 넣지 않는 것(기회비용이지 손실이 아님)이
핵심이었고, "놓치기 싫어서 안A로라도 채워 넣자"는 시도는 역효과였다
(0.163R < 0.199R).

## 4. tightening / vol_dry 가점 재검토 → 제거/전환 (v5.43 반영)

두 지표 모두 "VCP(변동성 압축 후 확장)" 전제를 코드화한 것 — 3.4의 범위
분석(넓을수록 좋음)과 같은 뿌리라 같이 재검토.

### 4.1 tightening (`analyze`/`analyze_imminent`의 캔들 수축 가점)

`tightening = 최근5봉 평균범위 < 그전5봉 평균범위`. 전체 유니버스 3622건
기준, 안A 결과를 tightening True/False로 분리:

| | n | 손절률 | 도달률(15%) |
|---|---|---|---|
| True | 2074 | 67.4% | 31.5% |
| False | 1547 | 68.5% | 30.0% |

차이 1.5%p — 오차범위. **실증 근거 없음.**

### 4.2 vol_dry (`analyze_imminent`의 거래량 수축 가점, 20점)

신호일 이후 N=10봉 이내 실제 "고가돌파+거래량1.5배" 발생 비율을 vol_dry
True/False로 분리:

| | n | 이후10봉내 거래량동반돌파 비율 |
|---|---|---|
| vol_dry=True(수축) | 1605 | **39.6%** |
| vol_dry=False | 2017 | **46.7%** |

**격차 7.1%p, 방향이 반대** — "돌파 전 조용함"이 실제 거래량 폭증 돌파를
예고하기는커녕 오히려 방해. tightening보다 명확한 반증.

### 4.3 처리 — score 반영에서만 제거, 필드 자체는 유지

- **tightening**: 순수 이진값이라 가점 완전 삭제(눌림목 5점/돌파임박 20점
  슬롯 제거). 반전(부호 뒤집기)도 검토했으나 top30의 60%를 흔들어(imminent
  기준 18/30 이탈, 최대 34계단) 기각 — 데이터가 가리키는 방향이라도 랭킹을
  과도하게 흔드는 변경은 신중해야 한다는 판단.
- **vol_dry**: 연속값(vol_ratio) 정보가 있어 "절벽(20 vs 연속식)"만 없애고
  정보는 유지 — `20 if vol_dry else 20*연속식` → 항상 `20*연속식`으로 통일.
  제거/반전/항목삭제 3안의 top30 영향 비교(재현오차 0.02~0.03으로 검증):

| | top30 이탈 | 평균순위이동 |
|---|---|---|
| A_제거(절벽만 무력화, 연속식 유지) | **3건** | 3.9 |
| B_반전(비수축에 가점) | 14건 | 15.1(최대37) |
| C_항목삭제(20점 슬롯째 삭제) | 12건 | 12.2 |

A_제거가 정보를 안 버리면서 가장 덜 흔들어 채택.

`tightening`/`vol_dry` 필드 자체는 `analyze`/`analyze_imminent` 반환값에
남아있음 — 카드의 "변동폭 축소" 배지(static/index.html)와 `app.py`의
강한피벗 풀(`_run_scan_strong_pivot`) `strength_score`(각 10점)에서 계속
사용 중. **이번 조사 결과가 그 두 곳에도 똑같이 적용될 여지가 있음**(같은
지표를 다른 이름의 스코어에 다시 쓰고 있는 것) — 이번 변경 범위에는 안 넣음,
필요시 재검토 대상으로 남김.

카드에 "신호일 고가(확인 트리거가)", "필요 거래량(50일평균×1.5)", "오늘
그 조건을 충족했는지"를 보여줘야 함.

- **신호일 고가**: 현재 `analyze_imminent` 반환값에 없음 — 추가 필요(단순,
  `h.iloc[-1]`).
- **필요 거래량**: `volume_info()`가 이미 `avg_volume`(50일 평균)을 반환 —
  ×1.5는 프론트에서 바로 계산 가능, 백엔드 변경 불필요.
- **"오늘 조건 충족 여부"**: 설계 미결. 스캐너는 매일 새로 스캔하는
  무상태(stateless) 구조라 "신호일"이 고정된 하루로 기록되지 않음 — 카드를
  볼 때마다 "오늘"이 곧 "신호일"이 되면 "오늘 충족?"은 항상 자명하게
  거짓(트리거가 그날 고가 자신이므로). 의미 있게 만들려면 (a) 프론트
  localStorage에 처음 본 날의 트리거가/거래량을 캐시해두고 이후 방문 시
  비교(journal/favorites와 같은 클라이언트 저장 패턴 재사용 가능), 또는
  (b) 트리거 기준을 "신호일 고가" 대신 "전일 고가"로 바꿔 매일 갱신되는
  롤링 체크로 재정의(측정한 방법론과는 살짝 다른 정의가 됨) 중 선택 필요 —
  다음 세션에서 결정.
