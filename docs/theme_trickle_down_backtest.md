# 서열별 낙수효과 백테스트 — "2·3등은 따라가고 4등부터 금지" 검증 (2026-08-29)

## 배경

테마로테이션 탭의 전제(측정 3번, `theme_map.py` v5.100 인프라의 첫 실사용)
— "대장주가 먼저 움직이면 2·3등이 뒤따라 오르고, 4등 이하는 안 따라온다"
는 실전 직관을 데이터로 검증한다.

## 이벤트 정의 — "테마 점화일"(D0)

theme_map.json에 매핑된 각 테마에 대해: 매핑 종목 합산 거래대금(종가×
거래량)이 자기 자신의 과거 60일 롤링 평균 대비 z≥2.0으로 급증 **AND**
정적 rank=1(Claude가 매긴 대장주)이 당일 +5%↑ 상승한 날. 시장 전체
대비가 아니라 테마 바스켓 자신의 시계열 대비(자기참조 z-스코어) —
jongga/gap-trade 백테스트의 "20일평균 대비 2배" 조건과 같은 방식.

## 매핑 데이터

"전력기기·원전"에서 1건 제거됐으나 실재 상장사가 이 앱 유니버스 밖이라
빠진 것이지 환각 아님): **2차전지·반도체·조선·화장품·K-뷰티·전력기기·

- z검정(규칙7): 연속형 % 수익률 2표본 z검정(표본분산) — jongga/gap-trade

- **시간 반분 생략**: 사전 등록 기준 자체에 요구되지 않았고(사용자
  지시 원문에 없음), 이벤트 수가 정적/동적 rank2-3 기준 43~44건으로

  라운드(매핑 확대 후) 후보로 남김.

## 판정 — 낙수효과 미확인, 4등 금지도 미확인 (관찰 기록)

**"낙수 유효" 미채택.** 정적·동적 rank2-3 모두 사전 기준(+1%↑ AND
z≥1.96)에 크게 못 미친다(z=0.36~0.62, 문턱의 1/3 수준) — 경계선
근접(has_maejip류 z=1.94)과 달리 명백한 미달이다.

**"4등 금지"도 미확인 — 오히려 방향이 반대다.** rank4+ 그룹의
비용차감후 수익률(+0.42%/+0.55%)과 승률(53.0%/54.0%)이 rank2-3
그룹(+0.75%~+0.49%, 44.2%/45.5%)보다 **오히려 나은 방향**이다. 단
어느 쪽도 통계적으로 유의하지 않다(rank2-3대비 z=-0.05~+0.28) —
"4등이 더 낫다"고 결론 내릴 근거도 아니다. 정직하게 말하면 **정적/
동적 rank, rank2-3/rank4+, 대조군 다섯 그룹이 전부 비슷한 수준의
낮은 수익률(+0.06%~+0.75%)에 몰려 있어 서열 자체가 D+1~3 구간에서
변별력이 없어 보인다**는 게 이번 표본에서의 솔직한 그림이다.

**규칙8과 같은 정신의 관찰**: 이벤트가 전력기기·원전(36건)에 크게
쏠려 있어(전체 97건의 37%) 이 테마 하나의 특이성이 전체 평균을
왜곡했을 가능성을 배제 못 한다 — 테마별 분해는 이번 라운드에 포함
안 했다(사전 등록 기준에 없었음, 다음 라운드 후보).

사용자 사전 지시대로 **"미달 → 관찰 기록, 매핑·스냅샷 더 쌓인 뒤
재측정 예약"**로 마무리한다 — 채택도 완전 기각도 아닌 관찰 상태.
