# 눌림목 스캐너 v2

우상향 추세 종목 중 이평선 지지 + 거래량 수축 눌림목을 찾아주는 웹 대시보드.
한국(KOSPI/KOSDAQ) + 미국 동시 지원.

## v2에서 추가된 것
- **RS 등급 (1~99)**: IBD 방식. 3/6/9/12개월 수익률 가중(최근 3개월 2배)으로
  유니버스 내 백분위 산출. 같은 시장(KR/US) 안에서만 비교. **RS 50 미만 탈락.**
- **200일선 필터**: 종가가 200일선 아래면 탈락 (하락추세 속 반등 제거)
- **피벗/손절/리스크**: 직전 10봉 고가 = 돌파 트리거(피벗),
  눌림 저점과 지지 이평선(1% 허용) 중 높은 쪽 = 손절 기준, 피벗 대비 리스크 % 표시
- 데이터 1년치로 확장 (상장 1년 미만 종목은 자동 제외)

## 탐지 조건 (전부 통과해야 표시)
1. 우상향: 종가 > 60일선, 종가 > 200일선, 20일선 > 60일선, 20일선 상승 중
2. 눌림 깊이: 60일 고점 대비 3~18%
3. 이평선 지지: 10/20/60일선 중 하나에 3.5% 이내
4. RSI 35~62
5. RS 50 이상
(거래량 수축·변동폭 축소는 점수에만 반영)

## 점수 (100점)
눌림 깊이 이상치 20 + 이평선 밀착 20 + 거래량 수축 20 + RSI 위치 15
+ RS 기여 15 + 변동폭 축소 5 + 고점 유지 5

조건 변경: `scanner.py` 상단 `CONFIG`

## 배포 / 실행
- Railway: GitHub 푸시하면 자동 재배포
- 로컬: `pip install -r requirements.txt` 후 `uvicorn app:app --reload`
- 종목 추가: `watchlist.txt` (한국 종목 .KS/.KQ 접미사 필수)

## API
- `GET /api/scan?market=kr|us|all` (10분 캐시), `&refresh=true`로 강제 재스캔
