# 눌림목 스캐너 v3

우상향 추세 종목 중 이평선 지지 + 거래량 수축 눌림목을 찾아주는 웹 대시보드.
한국(KOSPI/KOSDAQ) + 미국 동시 지원.

## v3.2
- **🔥 트리거 발동**: 당일 +4% 이상 양봉 + (하락 추세선 돌파 or 피벗 2% 이내/돌파)이면
  카드에 🔥 + 노란 테두리, 목록 최상단 고정. "예쁜 대기자"와 "지금 출발하는 종목" 구분.
- **돌파일 평가 보정**: +4% 이상 상승일에는 눌림 깊이·RSI·이평선 거리를 "전날(셋업)"
  기준으로 평가. 돌파 당일 신고가/RSI 급등 때문에 목록에서 사라지던 문제 해결.
- 이평선 밀착 점수 음수 방지 클램프.

## v3.1
- **미너비니식 피벗 자동 선택**: 타이트존(5봉 고가) / 전고(10·20봉 고가) / 하락 추세선
  중 현재가 위에서 가장 가까운 트리거를 선택, 카드에 종류 표시.
  추세선 = 최근 40봉 스윙 고점(최대 3개)의 하락 직선. 최근 3봉 내 상향 돌파 시
  "추세선 돌파" 배지 (조기 진입 신호).
- **관찰 딱지**: 피벗까지 +15% 이상이면 "관찰" — 지금은 매매 셋업이 아니라 워치리스트용.
- **U/D 거래량**: 최근 10일 상승일 거래량 ÷ 하락일 거래량. 전환 탭의 "거래량 확장"
  배지는 양(1.2×) + 방향(U/D≥1) 모두 충족해야 켜짐 (분배성 거래량 폭증 걸러냄).
- **주도주 횡보 베이스 허용**: RS 90+는 20일선이 10봉간 -2%까지 평평/완만 하락해도
  통과 (VCP 베이스 빌딩 중 정상 — 인텔 케이스).

## v3.0
- **RS 곱셈 점수**: 최종점수 × (0.7 + 0.3×RS/99). 힘(RS)과 모양 둘 다 좋아야 고득점.
  완벽한 모양 + 낮은 RS(MSCI류)는 순위가 내려가고, 강한 종목이 위로.
- **RS 모멘텀 (↗)**: 3개월 수익률 백분위 − 12개월 백분위. +10 이상이면 카드에 ↗ 표시
  + 눌림목 점수 +3. "올라오는 RS 53"과 "무너지는 RS 53"을 구분.
- **추세전환 탭 신설**: 역배열→정배열(20>60>200, 종가>200일선) 첫 전환이 최근 22봉
  이내인 종목. 조건: RS 모멘텀 ≥ 0, RS ≥ 30, 200일선 +25% 이내(추격 방지).
  점수 = 신선도 30 + RS개선폭 25 + 현재RS 15 + 거래량 확장 15 + 200일선 근접 15.
  피벗 = 60일 고가, 손절 = 60일선 −2%.
  ※ 전환 초입은 가짜 신호가 많음 — 눌림목보다 보수적으로 접근 권장.

## v2.1 주도주 모드
- RS 90+ 종목은 완화 기준 적용: 최소 눌림 1.5%(일반 3%), RSI 상한 72(일반 62)
- 가파른 주도주의 짧고 얕은 눌림(2~3%, 10일선 휴식)도 포착, 카드에 👑 표시

## v2에서 추가된 것
- **RS 등급 (1~99)**: IBD 방식. 3/6/9/12개월 수익률 가중(최근 3개월 2배)으로
  유니버스 내 백분위 산출. 같은 시장(KR/US) 안에서만 비교. **RS 50 미만 탈락.**
- **200일선 필터**: 종가가 200일선 아래면 탈락 (하락추세 속 반등 제거)
- **피벗/손절/리스크**: 직전 10봉 고가 = 돌파 트리거(피벗),
  눌림 저점과 지지 이평선(1% 허용) 중 높은 쪽 = 손절 기준, 피벗 대비 리스크 % 표시
- 데이터 1년치로 확장 (상장 1년 미만 종목은 자동 제외)

## 탐지 조건 (전부 통과해야 표시)
1. 우상향: 종가 > 60일선, 종가 > 200일선, 20일선 > 60일선, 20일선 상승 중
2. 눌림 깊이: 60일 고점 대비 3~18%
3. 이평선 지지: 10/20/60일선 중 하나에 3.5% 이내
4. RSI 35~62
5. RS 50 이상
(거래량 수축·변동폭 축소는 점수에만 반영)

## 점수 (100점)
눌림 깊이 이상치 20 + 이평선 밀착 20 + 거래량 수축 20 + RSI 위치 15
+ RS 기여 15 + 변동폭 축소 5 + 고점 유지 5

조건 변경: `scanner.py` 상단 `CONFIG`
